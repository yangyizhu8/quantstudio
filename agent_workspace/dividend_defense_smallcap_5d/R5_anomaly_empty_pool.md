# R5 异常报送：窗口前段结构性空池（空池期 anomaly）

- 发现于 R5 主跑第 1 跑（G3.5），**未自行处置**，按纪律随证据报送
- 证据：`%TEMP%/r5/run1.log`（运行中）+ 本文件诊断记录
- 结论：**这不是策略缺陷，是数据覆盖限制**；但**影响已确认的样本内外划分**，需客户裁定

## 一、现象

主跑窗口 2020-01-01 ~ 2026-07-31，从首日起：
```
Post-close 2020-xx-xx: held=[] pending_exits=[] div_cache=0     （持续）
...
Post-close 2022-01-24: held=['002107'] pending_exits=[] div_cache=1   ← 首次建仓
```

**空池期 = 2020-01-02 ~ 2022-01-21，约 500 个交易日（≈2.06 年，占全窗口约 31%）**，期间零持仓、零交易、净值平坦。

## 二、根因（分阶段诊断实证）

`probe_pool_stages.py` 在 2021-07-13（prev 2021-07-12）逐级计数：

| 步骤 | 剩余标的 |
|---|---|
| get_Ashares | 4,380 |
| 剔除科创板/北交所 | 4,073 |
| 非 ST | 3,961 |
| 未停牌 | 3,961 |
| 上市满 1 年 | 3,620 |
| 流通市值 > 5 亿 | 3,620 |
| income_statement 有年度数据 | 3,478 |
| **近三年归母净利润 CAGR > 15%** | **0** ← 全市场清零 |
| `_build_filter_pool` 返回 | **0** |

**直接原因**：决策日 2021-07-12 时，PIT 可见的最近年报年份 T=2020，规则要求 `NP(T-3) = NP(2017)`——
**本库 `income_statement` 的年度覆盖自 FY2018 起**（实测：年报 end_date 年份分布 2018…2025；
全表最早 end_date = 2018-03-31；年报最早 ann_date = 2019-01-22）。FY2017 及更早**根本不存在** → 全部标的无法计算 CAGR → 池恒空。

**可计算起点**：需 `T-3 ≥ 2018 ⟹ T ≥ 2021`，而 FY2021 年报最早一批于 **2022-01** 披露
→ 首次可能建仓 = **2022-01-24**（与实测一致）。

## 三、影响评估

| 面 | 影响 |
|---|---|
| 样本内 2020-01-01~2024-12-31 | **前 2.06 年完全空仓**（有效样本仅 2022-01-24 ~ 2024-12-31） |
| 样本外 2025-01-01~2026-07-31 | 不受影响 |
| R5.5 WF 五折 | 前 1–2 折必然 NO_TRADE → 不入 G5 分母；有效折数可能降至 3 |
| 客户三原则之一「不额外新增因子」 | 未违反（CAGR 规则原样执行，是**数据不足导致的数据性排除**，与设计 A-1 同类语义） |
| `r5_deployment_invariants` | 空池期 gross_exposure=0 属合法状态，但需在审计行显式标记；当前实现 note 仅在调仓日输出，**空池期需补标记维度** |
