一、问题原因（根因 + 实测证据）
────────────────────────────────
本线 R5 主跑（窗口 2020-01-01 ~ 2026-07-31）出现结构性空池：2020-01-02 ~ 2022-01-21 共约 500 个交易日零持仓、零交易（占全窗口约 31%）。

根因：客户策略规则「近三年归母净利润复合增速 > 15%」需要 NP(T) 与 NP(T-3) 两个年度值；
而本地 income_statement 的**年报覆盖自 FY2018 起**——
  · 实测年份分布：2018 / 2019 / 2020 / 2021 / 2022 / 2023 / 2024 / 2025
  · 全表最早 end_date = 2018-03-31；年报最早 ann_date = 2019-01-22
→ 决策日 2022-01 之前 NP(T-3) = NP(2017) 不存在 → 全市场无法计算 CAGR → 过滤池恒空。
  · 首次可能建仓实测 = 2022-01-24（与推算吻合）

定性：**数据覆盖缺口，非策略缺陷**（规则原样执行，属数据性排除）。
