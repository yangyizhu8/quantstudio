# PTrade 平台分红入账口径实证（div tax probe）

验证本地引擎分红税假设与 PTrade 平台真实行为是否一致：
- **股票**：本地 `_apply_corporate_actions` 按 `pre_tax × 0.80`（20% 短持红利税）
- **ETF**：本地阶段 2 `_apply_etf_cash_dividends` 按 `div_cash × 1.0`（公募基金分红免税）

> 背景：现有 PTrade 对齐样本（ETF动量/小市值/双均线）持仓期间**零除息事件**，
> 分红入账口径从未被 PTrade 实证验证（TD-DIV-TAX-ALIGN）。

## 操作步骤

1. PTrade 平台导入 `ptrade/div_tax_probe_stock_600000.py`，回测设置：
   - 初始资金 **100,000**；区间 **2026-07-01 ~ 2026-07-31**；日线
2. 同上导入 `ptrade/div_tax_probe_etf_510500.py`，同样设置
3. 回测完成后在平台导出三件套（与既有样本相同方式）：**交易详情 CSV + 持仓明细 CSV + Log.txt**
4. 把两个样本目录放入 `私募工作文件/ptrade_samples/`（如 `divtax_600000` / `divtax_510500`），
   告知本地做系数判定

## 除息日事实（tushare/本地库实测）

| 标的 | 除息日 | 每股/份分红 | 除息参考价吻合 |
|---|---|---|---|
| 600000 浦发银行 | **2026-07-16** | 税前 **0.42 元** | 07-16 preClose 8.89 = 07-15 close 9.31 − 0.42 ✅ |
| 510500 中证500ETF | **2026-07-15** | **0.149 元/份** | 07-15 preClose 8.264 = 07-14 close 8.413 − 0.149 ✅ |

## 判定方法（Log.txt 逐日 total_value）

```
除息日净值缺口占比 ≈ (1 − nav_T/nav_{T−1}) − pctChg_T    （pctChg = (close−preClose)/preClose）
```

理论缺口（按满仓 vol 股/份，占持仓市值比例）：

| 标的 | 不入账（系数 0） | 0.8 入账（股票口径） | 1.0 入账（ETF 免税） |
|---|---|---|---|
| 600000（股息率 4.51%） | **−4.51%** | **−0.90%** | ≈ 0% |
| 510500（股息率 1.80%） | **−1.80%** | **−0.36%** | ≈ 0% |

- 600000 结果 ≈ −0.90% → PTrade 股票按 0.8（与本地一致 ✅）；≈ 0% → 全额入账（本地需改口径）；≈ −4.51% → 不入账
- 510500 结果 ≈ 0% → PTrade ETF 免税全额（与本地阶段 2 一致 ✅）；≈ −0.36% → PTrade 对 ETF 也套股票税（本地需改）

## 顺带验证（持仓明细 CSV）

- **持仓成本价**列在除息日是否下降：本地股票路径 `avg_cost −= div`（0.42）、ETF 阶段 2 不改成本。
  观察 PTrade 是否一致。
- **交易详情**应只有 1 笔买入（无平台自动卖出干扰）。

## 结论回传

样本回传后，本地按上述公式判定系数 → 与本地假设（股票 0.8 / ETF 0.8，均已按 PTrade
实测对齐）一致则关闭 TD-DIV-TAX-ALIGN；不一致则按框架行为变更流程（确认 → 改口径 → 回归 → 同步）。

## 探针 3：股票送股/转增（`div_tax_probe_stock_split_300492.py`）

验证 PTrade 平台对**股票送股/转增**的处理（含与现金分红同日复合除权）。

- 标的：**300492 华图山鼎**，除息日 **2026-07-07**，10送4派1（stk_div=0.4 送股 + 现金 0.1）
- 回测设置：初始资金 100,000；区间 **2026-07-01 ~ 2026-07-31**；日线
- 除权参考价实测吻合：07-07 preClose 26.08 = (36.6 − 0.1) / 1.4 ✅

判断（Log.txt 的 amount/total/cash 序列）：

| 检查 | 期望（本地口径） |
|---|---|
| ① 送股 | 07-07 起 **amount ×1.4**（如 2700→3780） |
| ② 现金入账 | 07-07 cash 增量 = vol×0.1×**0.8**（股票口径，600000 已实证） |
| ③ 净值缺口（剔除涨跌） | **≈ −0.055%**（0.8 口径：0.2×0.1×vol/10 万）；1.0 口径 ≈ 0；不入账 ≈ −0.27% |
| ④ 成本摊薄 | 持仓明细"持仓成本价"07-07 摊薄 ≈ 买入成本×0.7（/1.4，送股摊薄） |

- amount ×1.4 + 净值缺口 −0.055% → PTrade 送股 + 现金 0.8 与本地一致 ✅
- 该探针同时闭合"股票送转的 PTrade 对齐未实证"盲区（此前样本持仓期间无送转事件）
- 本地 stock_dividend 的 stk_div 已含转增（实测纯转增 0 行、样例 stk_div==stk_co_rate），
  引擎 `_apply_corporate_actions` 一次覆盖送股+转增——探针 300492 验证送股代表路径即可
