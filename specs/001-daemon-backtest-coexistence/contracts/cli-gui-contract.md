# Contract: CLI 与 GUI 双端对等

**Date**: 2026-10-27 | **Plan**: [../plan.md](../plan.md) | **Spec**: [../spec.md](../spec.md) FR-013

本契约定义共存能力在两个入口上的**等价语义**。两端必须调用同一内核（`run_backtest`），不得各自实现。

## 语义契约（两端必须一致）

| 行为 | 语义 |
|---|---|
| 共存开关 | 默认**开启**；可显式关闭以回退到改动前行为 |
| 让路分级 | 任务边界阈值默认 30 秒，可配置（CLI 参数 / GUI 设置项） |
| 等待读数 | 每秒刷新「已等待 X 秒 · 阶段」，阶段枚举：`等待采集轮收尾` / `已请求中断当前任务` / `预检数据可用性` |
| 取消 | 等待态与运行态均可取消；取消后不得开始回测，采集不受影响 |
| 显式拒绝 | 数据不可用 ⇒ 明确错误文本 + 建议动作，不产出结果文件 |
| 队列 | GUI 队列上限 3；CLI 单次调用不排队（由用户/脚本自行串行） |
| 产物一致性 | 同一参数下两端产物逐位一致（哈希） |

## CLI 侧

- 入口：`quantstudio.backtest.run_ptrade_strategy` 的 `main()`（既有 argparse 结构）。
- 新增参数（语义契约，参数名以实现时既有风格对齐）：
  - `--no-coexistence`：关闭共存窗（回退开关）。
  - `--coexistence-boundary-timeout <sec>`：任务边界等待阈值，默认 30。
- 等待读数输出：写入 **stderr**（不污染正常产物输出流），格式 `[coexist] waited=<秒> phase=<阶段>`。
- 退出码：数据不可用被拒绝 ⇒ 非 0（与既有失败退出码约定一致）；用户取消 ⇒ 与"用户中断"既有约定一致。

## GUI 侧

- 入口：`BacktestWorker` → `run_backtest`（`workers.py:419`）。
- 控件：
  - 共存开关（复选框，默认勾选）在回测参数区。
  - 等待态：状态标签显示真实读数（复用 `progress` 信号，新增 `phase` 语义）；`stop_btn` 在等待态即可用（复用既有取消路径 `cancel()` → `BacktestCancelled`）。
  - 采集状态区：显示「因回测让路暂停」，与"采集故障"视觉区分。
- 队列：连点最多堆积 3 个；第 4 个立即拒绝并弹提示（含当前队列状态）。

## 对等性机检

| 检查 | 方法 | 判定 |
|---|---|---|
| 同参产物一致 | 同一策略 + 同一参数，分别从 CLI 与 GUI 发起（均无采集占用） | 输出目录产物哈希一致 |
| 开关对等 | 两端均能关闭共存 | 关闭后行为与改动前逐位一致 |
| 文案对等 | 两端等待读数格式不同但语义字段相同 | 阶段枚举一致（3 值） |

## 待实现确认项（不改变契约语义）

1. 现有 argparse 的实际参数风格（短横线/下划线、是否存在 `--` 前缀习惯）——实现时对齐，不改语义。
2. GUI 既有"设置项"落点（配置文件 vs 界面控件）——若不引入设置项，阈值取常量 30s 并在界面提示，仍满足契约。

## 退出码契约（CLI ↔ GUI 映射 · 2026-10-28 入册）

双端对等的**机器可读面**：CLI 退出码与 GUI 弹窗选项必须一一对应。

| 结局 | CLI 退出码 | GUI 表现 |
|---|---|---|
| 回测成功 | `0` | 完成提示 + 结果窗口（附「采集已因回测停止，请手动启动」） |
| 采集停止超时（`CollectorStopTimeout`） | `4` | 弹「继续等待 / 强制终止 / 取消回测」三选项 |
| 用户取消（`WindowCancelled`） | `130` | 「已取消（回测未开始；采集保持当前状态）」 |
| 数据不可用被拒绝（预检失败/取数失联） | 非 0（沿用既有失败约定） | 显式错误弹窗 + 排查指引；不产出结果目录 |

**三选项 ↔ 退出路径的映射**：

| GUI 选项 | 等价行为 | CLI 对应 |
|---|---|---|
| 继续等待 | 重入等待（同一停止上下文，计时累加） | 加大 `--coexistence-stop-timeout` 后重跑 |
| 强制终止 | `daemon_process.force_kill_daemon()` → 继续回测 | 无交互等价物（脚本场景需人工先杀，再 `--no-coexistence` 兜底） |
| 取消回测 | 不启动回测；采集保持当前状态 | `Ctrl+C` / 退出码 `130` |

> 强制终止仅限分级停止已失效的卡死场景（FR-019），未提交单元丢弃、水位不推进、下次启动重跑补齐。
