## 四、纪律与边界

1. **只读探针**：不下单、不写文件、不改框架；三件（A/B1/B2）均为 QMT 粘贴运行型。
2. **编码契约**：全部 `#coding:gbk` ＋ GBK 物理 ＋ 无 BOM ＋ 无 `U+FFFD`（**QD-2026-0001 复发防线**，本轮 A/B1 已过自检）。
3. **不越界**：B3 不硬造 API 探针（UI 面不可探）；B4 不双建（QMCH 立项已照准，随其 probe-first）。
4. **状态升级纪律**：探针读数只用于「升 registry 状态」与「登记缺口」，**不触发任何框架改动**；若探针暴露新缺陷 → 按零越权登记 ISSUES 候裁。
