## 1. 修复本体：排除口径切换与定义裁决

### 1.1 现状
- `ptrade_api.get_Ashares(date, exclude_bse=None)`：默认（None/False）**含北交所**；
- 过滤实现已就绪：`is_bse_market`（920 前缀 + BSE_LEGACY_TO_920 精确表，lru_cache）；
- fidelity 联动：`fidelity_exclude_bse`（P-D13 C1b 预留）。

### 1.2 口径裁决（本方案核心决策，需总调度确认）

**指令口径**："北交 920xxx/4xx/8xx"；**既有权威实现** `is_bse_market` = 920 前缀 + legacy 精确表（**注释明确"without blanket 4xx/8xx inference"**——blanket 推断曾被有意避免）。

**分歧实质**：4xx/8xx 段含**老三板/新三板/部分非 A 股码**，blanket 排除可能误伤；但用户口径明示含 4xx/8xx。

**裁决方案（推荐）**：排除谓词 = **920 前缀 + legacy 表 + 4xx/8xx 全段**（对齐用户口径——平台 `get_Ashares` 实测本就不含这些段，用户口径即平台实况的摄写）；实现为**新谓词 `is_bje_excluded(code)`**（不动 `is_bse_market` 权威语义——它被 BSE 合法消费方使用），避免污染既有函数。

**裁决点（请总调度批复）**：4xx/8xx blanket 排除 vs 仅 920+legacy——**推荐前者**（用户口径明示 + 平台实况摄写），实施期以 07-01 实测两口径数量差为附录（量差即两口径分歧的量化）。

## 2. P0 残差复跑（验收设计=指令验收本体）

排除默认落地后：
1. **本地宇宙实测**：排除前后对照（北交码数量实测，非假设——bse_count_probe 脚本已备，DB 释放即跑）；
2. **平台对照**：平台宇宙 4932-5009 区间（总调度 21.1 实测表：01 月 4997 ~ 07 月 4983/07-01 快照口径）；
3. **残差清单逐码分类**：排除后本地 vs 平台当月在册池 diff → 残差 = 平台侧幸存者/超额码证据 → **交总调度复核**（feeding PIT 正解校准——含退市日历 21.2 项衔接）；
4. **预期方向**（指令预判）：排除后本地可能**反超为少**——因本地静态全历史池退市码仍在（无退市日历过滤），排除北交后与平台当月在册的差主要由"本地含已退市沪深码"构成 → 印证 PIT 过滤（§3）价值。

## 3. 可选第二改动：PIT 退市日过滤（评估结论：**有条件纳入**）

**数据基础已就位**：stock_delist 334 条含退市日期（表结构实施期核验——DB 锁释放后 DESCRIBE）。

**方案**：宇宙构造叠加 `上市日 <= T AND (退市日 IS NULL OR 退市日 > T) AND 非ST@T` 三条件过滤——实现层 = get_Ashares 内 stock_delist 反查（**需 date 参数非空**；date=None 调用形态跳过 PIT 过滤保持兼容）。

**纳入条件（本方案裁定建议）**：
- **纳入**：stock_delist 结构含可用退市日期列（334 条实测覆盖足够）+ 实现改动 ≤ ~20 行（get_Ashares 内单点过滤）；
- **缓引**：若结构缺退市日期列或需大改——缓引登记（衔接 21.2 数据基建项），本包仅交付北交排除 + 残差复跑。

**倾向**：有条件纳入（334 条退市日历是本轮解锁的核心前置——不消费则残差复跑的"本地含退市码"残差无法收敛，复跑结论价值减半）。
