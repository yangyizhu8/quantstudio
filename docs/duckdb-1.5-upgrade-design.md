## 1. 问题定义

1. **支持面到期**：运行面被锁定在 duckdb 1.4.5，1.4 线 **2026-11-17 EOL**；解除条件只写在依赖文件的注释里，无到期复核装置。
2. **口径分裂**：同一件事在六处分别表达（声明 3 处、门禁 3 处），且前者的实现是「字符串前缀匹配」——无法表达「1.5.6 放行、1.5.5 拒绝」。历史事故（2026-09-23）已证「声明与运行环境脱钩」是真实风险。
3. **缺陷仍存**：ART index-delete 缺陷在 1.5.x 全线仍在（含 1.5.6），仅由静默变为 FATAL；本项目暴露面为 0（非唯一 ART = 0；41 PK 三臂不丢），故升级**不是**修缺陷，只是维持受支持。
4. **并行缺陷**：passthrough 全量覆盖链（`DROP+RENAME`）**每执行一次即静默清空目标表主键**（段 A 四组 + 段 B 12 组一致 1→0），不报错不告警；丢 PK 后果经 F2 实验精确化——带 `ON CONFLICT` 目标的 upsert 会**直接 BinderException 拒绝**（fail-loud），无 `ON CONFLICT` 的普通 INSERT 则可能插重复行。与版本无关（1.4.5 / 1.5.5 / 1.5.6 表现一致）。

## 3. 影响面（铁律 18 三审计）

| 审计项 | 结论 |
|---|---|
| 影响其他功能？ | **不**。判定口径变化只影响「哪些版本可启动」；`writers.py` 改动只影响 passthrough 覆盖链的约束保持，不改写入行与语义（双写哈希验证）。`config_lint` 新增规则在现状配置下**零告警**（67 个 passthrough 与 25 张带 PK 表交集为空）。 |
| 影响性能？ | **一处影响，已量化并登记**：A-14 实测唯一落在本引擎上的批量写路径（快照元数据刷新）在 1.5.6 上相对 1.4.5 慢 **4.04×（1000 行）/ 6.14×（300 行）**，5000 行 >90s 超时；绝对耗时真实百量级 3.9s，不影响正确性。处置 = 风险项登记 + 通知提示 + **单独立项**（不在本期改码）。 |
| 影响精度？ | **不**。不改回测/取数/PIT/复权口径；`RETURN` 行数、列集、内容哈希在 PT-01 改道前后必须逐位一致。 |

**判型**：①升级与门禁集合化 = **新增检测型**（判定口径变化，verdict 可被新版本改变，属「开始报告真相」）；②PT-01a = **纯恢复型**（回到「覆盖后 PK 仍在」的原态）；③A-14 = **新增检测型**（新增观测，不改行为）。

## 5. 回退条件

| # | 触发 | 动作 |
|---|---|---|
| 1 | 冒烟任一 FAIL 且 10 分钟内不可修复 | 立即回滚（降版 1.4.5 + 旧版打开验证 + 门禁复核） |
| 2 | daemon 无法以计划任务形态恢复 | 回滚并登记形态异常 |
| 3 | 旧版无法打开已升级库（与预期相反） | 回滚 + 登记为异常读数（预期不会发生：无格式门） |
| 4 | 覆盖链改动导致回归新增失败 | 单文件回退 `writers.py`（其余落点不受影响） |
| 5 | 窗口超 60 分钟仍未完成 | 停止推进，回滚，重排窗口（不带病离开停服态） |
| 6 | **门禁自检非 PASS**（W5 未得 `PASS 1.5.6` / 退出码 ≠ 0） | 回滚（降版 + R3/R4 复核），登记判定源读数 |
| 7 | **S5 `storage_version` > 68**（超出首跳支持上限） | 回滚 + 登记文件头读数；`storage_version` 属存储格式面，超限意味不可控 ⇒ 不带病推进 |
| 8 | **daemon 首轮日志命中 FATAL 关键词**（`Failed to delete all rows from index` 等缺陷文本） | 回滚 + 登记首轮日志片段；命中即视为 1.5.6 缺陷面在本项目暴露 |
| 9 | 库打不开 / WAL 异常膨胀（非升级所致） | 走既有收敛入口：`check_wal.ps1 -Force` / `check_wal.sh --force`（**禁手工删 WAL**），不计入本次回滚判据 |

回滚执行序列见 `specs/002-duckdb-1.5-upgrade/quickstart.md` §2（R1–R7，逐条含判据）。

## 6. 风险

- **R-3（最高）**：批量写劣化已实测 FAIL → 只登记风险 + 通知提示；若客户侧该表批次增大到千行量级，将出现 13s 级停顿（不影响正确性）。
- **R-1/R-2**：窗口内他线写者；计划任务形态（`schtasks /Run`，禁 `Start-Process`）。
- **R-4**：`writers.py` 两分支共 145 行，须限在语义内并做双写验证。
- **R-5**：`venv_miniQMT`（1.5.3）不升，登记只读消费者；其若开启写者入口将被门禁拒绝（通知须写明）。
