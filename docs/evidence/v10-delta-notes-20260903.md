# v10 → v10.3 增量变更说明（审核补档，2026-09-03）

> 背景：v10.0 经审核（Step 3 放行）后，v10.1/v10.2 两轮增量未走独立审计轮即上平台
> （第二十轮假阳性定谳后审核要求补档）。本文档补齐三段增量的"改了什么/为什么/影响面"，
> 并附 v10.3（本文件随附）的假阳性根因定谳与修复设计。

## v10 → v10.1（机械修复）

- **改了什么**：`QS_MINUTE_SYNTH` 打点门控从复用 `_QS_MINUTE_DIAG_DONE` 改为独立
  `_QS_MINUTE_SYNTH_LOGGED`（模块级定义 + 函数内 global 声明 + 首调置位）。
- **为什么**：v10.0 的 SYNTH 打点与 DIAG 共用 done 标志，DIAG 块在同次调用先置位 →
  SYNTH 行永不打印（第十七轮平台日志实证缺失）。
- **影响面**：仅日志打点（一行门控），合成逻辑不变。

## v10.1 → v10.2（两个实施 bug 修复，本地复现闭环）

1. **global 声明缺失**：`get_history` 内 `_QS_MINUTE_SYNTH_LOGGED = True` 赋值使该名
   成为局部变量，`if not` 先读后赋 → UnboundLocalError → 平台被外层 wrapper 吞掉 →
   **合成块从未执行**（第十八轮 SYNTH 行缺失的真实根因）。修复：global 声明补该名。
2. **合成函数调用参数顺序颠倒**：签名 `_qs_synth_minute_bar_from_data(code, df)`，
   调用处误写 `(df, code)` → df 被 str 替换、合成恒 False。修复：两处调用改
   `(code, df)` 顺序。
- **验证**：本地复现链（产物 exec + FakeData 捕获 + wrapper 调用）→ SYNTH 行出现 +
  合成行 close=6.05 + gate PASS。**教训**：wrapper 实施必须在本地完整复现调用链
  （含作用域/参数序），平台只做终验——此前两轮把平台当测试场，浪费两轮往返。

## v10.2 → v10.3（第二十轮假阳性定谳 + 修复）

**假阳性根因（权威日线证伪链）**：000017/001237 于 07-01 全天未触板（high=6.29 <
涨停价 6.73 / high=75.99 < 78.89），任何分钟粒度不可能含涨停价；两笔买入为假阳性。
**机制重建**：平台回测 `data[code]` 在 07-01 09:31 提供的是【昨日（06-30）bar】
（close=昨日封板价 6.12、preclose=前日收盘 5.56——与平台分钟 `get_history
include=False` 返回昨日 bars 同源，平台回测数据面整体滞后一日）。v10.2 把昨日 bar
合成进返回体 → `last_close=6.12`、`pres[-1]=5.56` → `lp=5.56×1.1=6.116` → 触发。
001237 同构（close=71.72、preclose=65.20 → lp=71.72 → 触发）。**候选筛选条件=
"T-1 封板"（昨收≡昨日涨停价）→ 用昨日 bar 判 `close ≥ preclose×1.1` 对每个候选
恒真——100% 假阳性生成器**（600363/603983 未买仅因 MAX_HOLDINGS=2 截断，审核怀疑
证实）。本地引擎 `data[code]`=今日当前 bar（6.05）→ 本地不触发（双端分歧=活体
不一致样本）。

**v10.3 修复（三件）**：
1. **日期守卫**：合成行 bar 日期 == 当前交易日（`_QS_RUNTIME_CTX.current_dt`，捕获行
   升级为 `_qs_capture_data(context, data)` 双捕获）才合成；stale bar 拒绝（fail-open
   返回体保持原样 → 策略判定不触发）。
2. **三元组审计**（审核定位要求 1）：`QS_MINUTE_SYNTH` 行打印每码
   `[close=X preclose=Y t=Z]`——一轮运行即可定谳"合成 close 错 / 涨停基准错 /
   平台 stale bar"三假说。
3. stale-bar 拒绝打点：`=stale-bar` 标志（平台实证轮的直接判据）。

**本地验收**：三场景复现（今日 bar 合成 True + 三元组 / stale bar 拒绝 + 返回体 3 行 /
断板反包零捕获行）；fund_matrix 复证（42 契约测试 → 哈希 d1c47919）+ CONTRACT GATE
PASS。E2E：duckdb 写锁竞争依旧（挂起栈与 v9 对照一致，环境性 BLOCKED 维持）。

**影响面**：v10.2 的假阳性触发路径被切断（stale bar 拒绝）；本地引擎行为不变
（今日 bar 正常合成）；平台正确语义下（实盘/模拟盘 data=实时 bar）合成正常生效。
