## 三、新契约事实（**候裁**：是否升 registry 独立行）

> **`get_market_data_ex` 参数优先级：`count` > `start_time`**
> 证据：`{count:3, start_time:'20240102'}` ⇒ 返回 `20261014..20261016`（最新 3 行），**`start_time` 未生效**；而 `{count:3}` 单独使用返回同样的最新 3 行。
> 影响面：任何「以 count 限制行数又指望 start_time 定位起点」的调用都会**静默取到最新数据**（无报错）——与既有 `endDate 空串→静默空`（D-22/QCAL-05）同类**静默语义陷阱**。
> 处置建议：登记为 registry **DAT 族新行**（或并入 DAT-05..15 notes），并在 QB 侧检查既有 wrapper 调用是否同时传 count＋start_time（**潜在静默偏差面**）。
> **本轮不擅自新增 registry 行**（结构变更须走确认）——**候裁**。
