## 四、候选定谳（强证据）

> **中途终止 daemon（批写中途）→ WAL 尾部残留未完成事务 → 下次打开库时 WAL 回放遇致命错误
> → DuckDB 原生层终止进程（exit 0xFFFFFFFF）** —— 全程**无 Python traceback、无业务日志、未写库**。

- 与客户「12h 增量最后无声退出」**同型**，且形态覆盖「CHECKPOINT 后 DEAD」；
- 机理自洽：致命回放错误发生在 Python 异常体系之外（原生终止），故**不产生 traceback**；
  banner 未写、WAL 未动，均与「死在库打开/回放」一致。
