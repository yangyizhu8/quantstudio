## 三、与 X 类机制对比（辨"同源"还是"异源"）

| 维度 | X 类（513530.SH 等） | **D 类（512250.SH）** |
|---|---|---|
| 幂律 `ln f = k ln r + c` | **k 近整数、R²≈0.9999** | **k=0.017、R²=0.012（无幂律）** |
| 截距 c | +0.006 ~ +0.032（随 k 成比例） | +0.0190（但不随 k，因 k≈0） |
| f 形态 | 随 r 变化（f 有 0.83~0.97 的分布） | **恒定 1.0197（与 r 无关）** |
| j 形态 | 1.33 / 1.6~1.7 / 0.65 等（码级聚集） | −0.77 ~ −0.81（码内聚集） |
| 判定 | **整数次施加 + 锚偏移（小数 c）** | **恒定乘子失真（非幂律）** |

⇒ **两者不同族**：X 类的 `c` 与 `k` 成比例（同一机制的表现），D 类的 `f` 与 `r` 无关（另一机制）。
**不可用同一处方处理**。
