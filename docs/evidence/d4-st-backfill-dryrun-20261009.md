### 3.1 边界定性（已完成，阻断解除）

**结论：既非数据事实异常，也非 ASOF 缺陷——是本次回填脚本自身的日界口径缺陷。**

| 项 | 实测 |
| --- | --- |
| `stock_daily.time`（002743，更名后首日） | `1788796800000` = UTC 2026-09-07 16:00 = **CST 2026-09-08 00:00** |
| `stock_namechange.change_date`（002743 ST 更名） | `1788796800000` = **同一值** |
| ⇒ ASOF `row.time >= change_date` | 在 **2026-09-08** 精确命中 ⇒ 语义正确 |
| 首版脚本缺陷 | ① 标签少加 8h（把 09-08 显示成 09-07）；② 区间上界多加 8h（起点落到 08-17） |
