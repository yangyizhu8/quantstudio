## 2. 与 38096 案的关系（**撤销外部执行者假设**）

10-12 00:28 那次（daemon 38096）现象为：**日志在 00:27:59 骤停** + 进程存活但失响应 + 最终被外部关闭（当时归因「外部强制终止·执行者待确认」）。
本次在**可控条件下复现同一签名**（日志骤停 + 持续高 CPU 空转 + 不自行退出）⇒
**归因转向停服路径自身**，「必有外部执行者」的假设**不再必要**。

## 3. 候选根因（未证实·待取证）

1. **busy-wait**：收尾路径中存在不睡眠的轮询循环（如 `_running=False` 后仍 spin）；
2. **线程/子进程未 join**：非守护线程或子进程在主线退出后仍被等待；
3. **收尾阻塞在不可完成的条件**上（如等待某个永不满足的事件）而外层以自旋方式重试。

## 4. 取证路径（候窗口）
