# KB 指标定义：R / B / H（A7 · 2026-10-21）

> 用途：把「知识库到底起没起作用」从观感变成可机读取数。三项指标各自独立，**不得互相替代**。
> 权威约束：字段名与 `scripts/kb_preflight.py --json` 输出**逐字对齐**（见 §5），改字段即改本文件。

## 1 R · 复发次数（Recurrence）

**定义**：同一 **symptom 族**重复出现的次数。
**族判定**：`fix_layer` 相同 **∧** `symptom` 关键词交集非空（两者同时满足才算同族；关键词取 symptom 中的技术名词，人工判定后固化到条目）。
**数据源**：条目 frontmatter 的 `recurrence` 字段（整数，默认 0）。
**取数式**：

```
R_族 = Σ(该族各条目的 recurrence)
R_本轮 > 0  ⇒ 判「同坑复发」⇒ 按铁律「先修管线再修漏洞」处置
```

**现行读数**：`R = 1`（仅 [QD-2026-0001](../qmt/QD-2026-0001.md) `recurrence: 1`，GBK `≪`(U+226A) 复发，台账依据见 `docs/ISSUES.md` D-33 批 3 行；其余 8 条为 0）。
**局限（如实）**：`recurrence` 为人工维护字段，**不是**自动计数；自动计数需能判定「同一坑再次出现」，目前无此机检能力。

## 2 B · 盲区数（Blind spots）

**定义**：本轮缺陷/坑中，**「库内无对应条目」且「preflight 无命中」**的计数。
**数据源**：`docs/ISSUES.md` 本轮新增缺陷行（全集 N_def）∩ `kb_preflight.py --json` 的 `hits`。
**取数式**：

```
N_def      = 本轮 ISSUES 新增缺陷/坑行数
覆盖        = { 本轮新增或更新的 QD 条目 } ∪ { hits[].qd (对同一 symptom 的预检) }
B_本轮     = N_def − |覆盖 ∩ N_def 对应的缺陷|
```

**判读**：`B > 0` ⇒ 本轮出现了知识库尚未收录的新坑（正常，是「发现」）；连续多轮 `B` 不降 ⇒ 沉淀速度跟不上发现速度（管线问题，不是正常态）。
**局限（如实）**：「同一条缺陷是否被覆盖」需要人工把 ISSUES 行 ↔ QD 条目做一次对应；preflight 只能证明「规则触发过」，不能证明「人认为已覆盖」。

## 3 H · 命中率（Hit rate）

**定义**：`H = 命中调用数 / 总调用数`。
**命中判定**：一次 preflight 调用中 `hits` 数组**非空** ⇒ 该次调用计为「命中」。
**数据源**：每次 `kb_preflight.py --json` 输出的 `hits`（判命中）＋ 调用方台账（判分母）。
**取数式**：

```
H = count(调用 where len(hits) > 0) / count(调用)
```

**重要边界（防误读）**：
- `hits` ＝ **本次实际命中**的条目（规则触发 → 反查条目），**不是**库内条目全集；
- 库内（域过滤后）条目全集看 `kb_ids`，条目计数看 `kb_entries`；
- 脚本**不落盘调用日志**（只读、无副作用原则）⇒ **分母必须由调用方记录**（`orchestrator.py::_write_qmt_product` 写盘点 / CI / 人工运行台账）；
- 若某轮调用量少（如 < 10），H 不具统计意义，只作趋势参考。

## 4 三项指标的关系（防混用）

| 指标 | 回答的问题 | 责任方向 |
|---|---|---|
| **R** | 同一个坑是否又踩了一次？ | 回哺链是否生效（库→管线） |
| **B** | 这轮有没有库外的新坑？ | 沉淀速度是否跟得上发现 |
| **H** | 预检是否真的被触发过？ | 门禁是否真的在跑（而非空转） |

三者独立：`H` 高不代表 `R` 低（可能天天命中同一条）；`B` 高不代表 `H` 低（可能是调用少）。**禁止用任一项单独宣称「知识库有效」**。

## 5 字段名对齐表（逐字，改任一列即改本文件）

| 指标位 | 机读字段 | 出处 | 形状 |
|---|---|---|---|
| 命中条目 | `hits` | `kb_preflight.py --json` | `[{qd, domain, rule, path}]` |
| 命中判定 | `len(hits) > 0` | 同上 | 布尔 |
| 条目全集 | `kb_ids` | 同上 | `["QD-2026-0001", …]`（域过滤后） |
| 条目计数 | `kb_entries` | 同上 | int |
| 阻断项 | `block` | 同上 | `[{rule, qd, msg}]` |
| 提示项 | `warn` | 同上 | `[{rule, qd, msg}]` |
| 判定 | `verdict` | 同上 | `"BLOCK"` \| `"PASS"` |
| 复发次数 | `recurrence` | 条目 frontmatter | int ≥ 0 |
| 缺陷全集 | ISSUES 行 | `docs/ISSUES.md` | 行文本（D-xx 编号） |
