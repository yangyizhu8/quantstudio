## 1. 检查项结果明细

### A. is_qfq 语义审计（T1）

| 表 | is_qfq True | is_qfq False | False 占比 | 结论 |
|---|---|---|---|---|
| etf_minutes | 221,129,068 | 5,153,544 | 2.28% | 97.7% True + 51 code 整段 False |
| etf_daily | 10,801,491 | 0 | 0% | 100% True |
| stock_daily | 9,687,041 | 445 | 0.005% | 99.995% True |

- **A2 除权假说检验**（抽 510300/515050/000001/600519，定位 adj 变化日）：
  - 515050.SH 2026-05-13：adj 1.0→3.0（+200%），close 1.11→1.16（连续，未按折算调整）→ **close 为 qfq 语义**（已复权），与「raw」陈述矛盾。
  - 510300.SH 2018-03-30：adj 1.0→1.093，close +9.16%（当日真实涨幅主导），front 变化 +19.3%（≈adj 变化×close 变化的复合）→ 不满足 raw 连续假说。
  - 000001.SZ/600519.SH：除权日 front 变化 1.6%~8.2%，大部分落在 q90 参照（2.9%~6.3%）内 → 股票日线 close 亦为 qfq 语义。
- **A3 还原一致性**：`close × adj_i/adj_latest` 序列在除权日**系统性断裂**（见 F）→ 云端存储 = qfq 价 + raw 因子，**还原公式不适用**，还原必须改为「直接用 qfq close」或「raw 价 = qfq ÷ 因子」。

### B. 因子污染审计（T2，07-01 事件）

- **B1 尖刺全量扫描**（回落 >50% 且持续 ≤2 日恢复）：
  - `etf_minutes`：75 条尖刺 / 74 code，**date_hist = {2026-07-01: 74, 2026-05-25: 1}**。样例：159909.SZ adj 9.792→1.0（-89.8%）→07-03 恢复 9.792。
  - `stock_daily`：42 条 / 2 code（920123.BJ、920627.BJ），2020-2022 分散抖动（adj 在 1.0/2.14 间往复），判**个案**（北交所老股复权口径问题，需个案核验）。
  - `etf_daily`：0 条（因其 07-01 本就缺数，无法呈现尖刺）。
- **B2 精确污染范围**（06-30 adj>1 → 07-01=1.0 → 07-03 恢复）：**234 只 code**（etf_minutes 日级末值口径），adj 中位数 1.29、最大值 15.38。**同一时间点大量 code 因子归 1.0 再恢复 → 判定为云端批量写库事故**。
- **B3 污染时间窗**：尖刺集中于单一时间点（2026-07-01）→ 一次批量事故，非「世代切换残留」（残留应为永久值差而非 1~2 日回落恢复）。
- **B4 同日日线缺失**：`etf_daily` 2026-07-01 仅 74 code 有数据（6/30 有 2045、7/02 有 2039）→ **07-01 云端日线批量缺失 + 分钟因子批量归 1.0 = 同一事故**。74 只中 40 只与分钟污染 code 重合，其余为 07-01 当日 adj 本为 1.0 的新上市 ETF。

### F. 因子-价格一致性（T4）

- front 断裂（除权日 |front_ret| > 20%）：**etf_daily 303 条 / 262 code**；**stock_daily 4192 条 / 2350 code**。
- 抽验证据：515050.SH 2026-05-13 adj +200% 而 close 未动 → front +212%（= qfq 价的必然断裂）；159220.SZ 2025-11-10 adj 1.0→2.0 close 0.608→0.615 → front +102%；588100.SH（is_qfq=False）2026-07-23 adj 1.0→3.0 close 未动 → front +190%。
- **判定**：断裂非「因子或价格单点错误」，而是**云端同时存储 qfq 价与原始 adj_factor**，对已复权价再套 front 公式必然断裂。此混搭直接威胁所有依赖 `raw = close_raw × adj` 或 `front = close × adj_i/adj_latest` 的还原路径（本地 510020 front=raw×0.1006 污染疑云与此同源）。

## 2. T1~T4 判定结论

| 目标 | 结论 | 依据 |
|---|---|---|
| **T1 is_qfq 语义** | **云端 close = qfq（已前复权）语义**；`is_qfq` 列 97.7%~100% True 与数据行为一致；51 只 code 标 False 但行为仍为 qfq → **标记矛盾**；与「分钟是 raw」陈述矛盾 | A1/A2/A3 |
| **T2 07-01 污染** | **批量写库事故**：etf_minutes 234 只 code 因子归 1.0（07-01→07-03 恢复）；同日 etf_daily 1965 只 code 缺数。**污染在云端源头仍存在，重拉会重新拉入** | B1~B4 |
| **T3 价格质量** | 基础合法性优秀（24 行占位数据个案）；量价 1.18% 偏离 + 36% 零量 bar 为注意项；raw OHLC 可信 | D1~D3 |
| **T4 完整性/一致性** | 完整性中等：etf_daily 缺 08-11~14 + 07-01 批量缺数、10 只 code 源头断档；一致性差：qfq 价 × raw 因子混搭导致 front 系统性断裂 | E1/E2/F |

## 3. 最终判定

> **云端源头不满足「全量重拉基线冻结」前提。**

理由（三条硬伤）：

1. **07-01 批量写库事故残留在云端源头**：分钟表 234 只 code 因子在 07-01 归 1.0（07-03 才恢复），日表 07-01 缺失 1965 只 code —— 若直接全量重拉，事故数据会被再次拉入并固化为新基线。
2. **云端语义为 qfq 价 + raw 因子混搭**：与「分钟是 raw」的既有陈述矛盾；下游任何按 raw 还原的路径都会被系统性污染（front 断裂 303/4192 条为直接证据，本地 510020 污染疑云同源）。重拉前必须先统一并验证云端 price/adj_factor 语义口径。
3. **完整性缺口**：etf_daily 缺最近 4 个交易日（08-11~14）且 07-01 批量缺数；10 只 ETF code 源头断档（最长缺 383 交易日）——基线冻结需要覆盖完整交易日历，否则基线本身不齐。
