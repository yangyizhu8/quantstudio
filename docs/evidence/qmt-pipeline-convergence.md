# QMT 管线收敛台账（N_i / R_i 计量）

> 建立：2026-10-12（M5.2 件3，总调度批准立项）
> 性质：QMT 转换管线漏洞收敛的逐轮计量档案——衡量「验证→修复→沉淀→回哺」闭环是否真实收敛
> 刷新纪律：每轮六步⑥推送后与 PROJECT_STATE 同轮簿记刷新（簿记豁免白名单内）

## 计量定义

- **N_i** = 第 i 轮新登记的 QMT 管线缺陷数（D 编号）
- **R_i** = 第 i 轮缺陷中命中「知识库已有同类条目」的**复发**数（坑已在库/矩阵/契约表还踩 = 回哺链断裂）
- **收敛判据** = 连续 3 轮 R_i=0 且 N_i 单调递减趋零
- **R_i>0 处置预案**：出现复发 → 先归因三选一（①主库缺条目 → 补条目；②回哺链断裂 → 修管线回哺机制；③矩阵门漏覆盖 → 补矩阵覆盖）→ **先修管线再修漏洞**，禁止直接补丁了事（杜绝拆东墙补西墙）
