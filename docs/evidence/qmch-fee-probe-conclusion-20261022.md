## 一、QMCH-01 撮合价口径 —— **已锚定**

| 委托类型 | 撮合价 | 证据（隐含费用法） |
| --- | --- | --- |
| **限价单**（prType=11） | **委托价** | v4 A/B 双变体 × 高低双向 **4 个数据点** |
| **市价单**（prType=5） | **当日 close** | v5 单点 |

**读数（变体 A：佣金 0.035%／最低 5 元／卖印花 0.1%／滑点 0）**
```
K1A code='000001.SZ' close=11.663108 high=11.702246 low=11.398927 => limit=11.70
    K1A CASH delta=-1175.0 => gross=1175.0000
    implied_fee{ORDER_PX:5.0000, CLOSE:8.6892, OPEN:32.1719, HIGH:4.7754, LOW:35.1073}
K1B code='000002.SZ' close=3.14 low=3.07 => limit=3.13
    K1B CASH delta=-318.0 => gross=318.0000
    implied_fee{ORDER_PX:5.0000, CLOSE:4.0000, OPEN:11.0000, HIGH:-2.0000, LOW:11.0000}
```
**读数（变体 B：佣金 1%／最低 0／卖印花 1%）**
```
K1A CASH delta=-1181.70 => implied_fee{ORDER_PX:11.7000, ...}   (1170 x 1% = 11.70)
K1B CASH delta=-316.13  => implied_fee{ORDER_PX:3.1300,  ...}   ( 313 x 1% =  3.13)
```
⇒ **只有「委托价」假设的隐含费用精确等于理论费用**（A=5.0000；B=11.70/3.13），其余假设全部偏离。

**市价单（v5）**
```
L2B code='000002.SZ' close=3.14（市价单，无委托价）
L2B_MARKET BUY sent px=0 prType=5 vol=100
L2 市价买 CASH delta=-319.0 => implied_fee{CLOSE:5.0000, OPEN:12.0000, HIGH:-1.0000, LOW:12.0000}
```
⇒ `100×3.14 + 5.00（最低佣金）= 319.00` **精确** ⇒ **市价单按当日 close 成交**。

## 二、QMCH-02 涨跌停 —— **已锚定（涨停侧）／跌停侧缺口**

**涨停可成交（无封板约束）**：
```
K2 candidate code='000011.SZ' chg=0.0997 close=9.49 preClose=8.63 date=20260908
A: bar7 avail 999640.86 -> 998686.86  (delta=-954.00 = 949 + 5.00)     精确
B: bar7 avail 999619.37 -> 998660.88  (delta=-958.49 = 949 + 9.49)     精确
```
⇒ 涨停价挂单**即成交**，与本地引擎 `limit_up_blocked` 拒单**不一致**。

**跌停侧缺口（如实登记，不推断）**：
```
L3 state=NO_LIMIT_DOWN_SAMPLE(前60只当日无 <=-9.8%)     ← v5：没扫到样本，≠ 无约束
跌停卖出 = NOT_TESTABLE（需提前持仓且当日恰好跌停，不可控）
```

## 三、QMCH-03 T+1 —— **已锚定：回测引擎实施 T+1**

**引擎原文（最硬证据）**：
```
[系统]WARNING:当前股票000001.SZ可卖0股,小于需卖量100股,跳过,日期时间:20260901 00:00:00
```
**配套资金读数**：
```
L1A_BUY BUY sent px=11.7 vol=100
L4 同bar_买入后 avail=998825.0 => sameday=VISIBLE
L1A_SELL_SAMEBAR SELL sent px=11.7 vol=100     ← 被引擎跳过
L1 T1 判定 base=1000000.0 avail=998825.0 delta=-1175.0 参照:只有买成交=-1175.0 买卖都成交=-10.0
L1 T1 结论=T1_ENFORCED_SELL_REJECTED
```
⇒ 当日买入**不可卖**（可卖量=0），delta 精确等于「只有买成交」。

> **撤回声明**：v3/v4 曾标 `T0_ALLOWED` —— **判据无效**（当时卖出发生在买入后第 4 个 bar，早已过 T+1），已作废。

## 四、FEE 四格 —— 三项按面板生效 ／ 过户费**已知分歧**

| 编号 | 结论 | 读数 |
| --- | --- | --- |
| FEE-01 最低佣金 | **按面板生效** | A 变体两笔均 5.00（1170×0.035%=0.41 < 5 ⇒ 取地板）；B 变体最低佣金设 0 后不再取 5 |
| FEE-02 佣金费率 | **按面板生效** | B 变体 1% ⇒ 11.70 / 3.13 / 11.40 三处精确 |
| FEE-03 卖出印花税 | **按面板生效** | A 0.1% ⇒ 1.14；B 1% ⇒ 11.40 |
| **FEE-04 过户费** | 🔴 **已知分歧：本地有公式，QMT 回测恒 0／未实现** | A 卖出费 `6.14 = 1.14(印花) + 5.00(佣金)` **无余项**（理论过户费 0.0114 缺失）；B 卖出费 `22.80 = 11.40 + 11.40` **无余项**（理论过户费 0.0114 同样缺失）⇒ 双变体交叉印证 |

**卖出侧完整算式**
- A：`1140.00 − (1.14 + 5.00) = 1133.86` ⇒ 实测 `up=1133.8600` ✓
- B：`1140.00 − (11.40 + 11.40) = 1117.20` ⇒ 实测 `up=1117.2000` ✓

## 五、五轮探针演进（含我方三次判据缺陷，如实记载）

| 版本 | 修了什么 | 本版暴露的坑 |
| --- | --- | --- |
| v1 | 初版（安全闸／DEAL 读成交／涨跌停扫描） | 🔴 **A1 假阴性**：`_has(globals(),'get_Ashares')` 恒 False ⇒ 标的池永远空 ⇒ `NO_CODE`／`NO_LIMIT_SAMPLE` 全是假警报 |
| v2 | 修 A1；加账户兜底、上下文诊断、FEE 字段 | 🔴 **DEAL 不可用**（回测不提供成交明细）；🔴 **ACCOUNT 半初始化**（`m_dAssetBalance=0`、`m_dCommission=1.797e308` DBL_MAX 哨兵）；🔴 **取价错配**（`count=2` 末行非回测当日，委托价被引擎改写）；🔴 **v2 自身缺陷**：QMCH-02 段只认 `get_Ashares`，`NO_POOL` 仍是假阴性 |
| v3 | 取价改按 `get_bar_timetag` 当日；成交判定改资金差；市价兜底 | 🔴 **J4-2 日期缓存缺陷**：QMCH-02 用缓存日期取价，下单日已推进 ⇒ 样本作废；🔴 **T0_ALLOWED 误判**（下一 bar 读现金 + 间隔 4 bar ⇒ 测不到 T+1） |
| v4 | 撮合口径判别（隐含费用法）；QMCH-02 日期实时取；限价卖出 | 结论成立；但仍未能测 T+1（判据设计仍错） |
| v5 | **同 bar 买后立即卖**（真 T+1 判据）；市价单口径；跌停扫描 | 跌停无样本 ⇒ 如实记缺口 |

**教训（跨版本共性）**：
1. **判据必须"先测后定"**——三次缺陷的共同根因都是**没验证判据本身能否区分目标量**（假阴性/日期缓存/间隔过远）；
2. **自检阈值必须"先数后断言"**——三次自检报红全是阈值凭记忆写错（`≥2` 写死而实际为 1），噪音掩盖真缺陷；
3. **PowerShell 不得用于改含中文的源码/脚本**——PS 5.1 以 ANSI 读 UTF-8 会把中文碾成 `€`（实测 `UnicodeEncodeError: '\u20ac'`）。

## 七、回测 API 面总账（五轮沉淀，供后续探针直接复用）

| 项 | 事实 |
