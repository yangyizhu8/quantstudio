# P-D9 双端选股差异归因证据 — filter_stock_by_status('ST') 候选池语义差（2026-08-22）

- 关联：登记表 P-D9（新登记，pending）+ 双端回测日志（本地 20260822_042022 vs PTrade 测试456 04:19:30）
- 归因提出：ZCode；核验：DSH 代码行级 + stock_daily DB 实证

## 1. 现象

双端同刻回测（2026-07-01~07-31，10 万资金），选股仅 1/5 重合：

| 端 | 选股 | 股价区间 |

| PTrade | 000004 / 002808 / 002898 / 300029 / 300854 | 0.15~0.51 元（4 只仙股） |

## 2. 根因（确定性，非噪声）

**本地 `filter_stock_by_status('ST')` 含"退市风险兜底"，平台仅官方 ST 标记**：

- 本地语义（ptrade_api.py:817-822）：`'ST' = is_st_reliable OR is_delisting_risk`
  - `is_delisting_risk = close<1 OR 近20日 circ_mv<5亿`（退市风险兜底）
- 平台语义：'ST' 仅官方 ST/*ST 名称标记（退市整理期仙股无 ST 标记 → 留在池内）
- 策略调用（vol_regime L214-215）：`filter_type=["ST","HALT","DELISTING"]`

**stock_daily 实证（07-01）**：

| code | close | is_st_reliable | is_delisting_risk | source |
|---|---|---|---|---|
| 000004 | 0.37 | False | **True** | price |
| 002808 | 0.23 | False | **True** | price |
| 002898 | 0.35 | False | **True** | price |
| 300029 | 0.15 | False | **True** | price |

→ 4 只仙股本地 'ST' 分支**必剔**（进不了本地候选池）；平台保留 → 入池。
→ 反转策略选"最近 12 个月最跌"：仙股从几元跌至 0.15-0.37（跌幅 80-95%）为全横截面最极端跌幅 → **必然霸榜前 5**。
→ 两端选股差异 = P-D9 池差（决定性）+ D3 边缘差（剩余席位抖动，次因）。
