## 5. 待确认点（B2 精确分量——**D3 机理实证后归零**）

```

560780: 07-01 08:00（异常组）close=1.469   ← D3 前不可见 → 旧版未选
588170: 07-01 00:00（正常组）              ← 两版首日均选（相同）
```
