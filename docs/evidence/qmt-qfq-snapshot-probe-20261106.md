## 一、本地复权实现链（V0-1/V0-2）

```text
策略 get_history(fq='pre')
  → ptrade_api get_history → query_bars_by_range(use_qfq=True)
  → SELECT open_front AS open, high_front AS high, low_front AS low, close_front AS close
    FROM stock_daily WHERE code=... AND time BETWEEN ...
```

- **同表同行物化**：`stock_daily` 同时存 raw（open/high/low/close）、front（*_front）、back（*_back）与**比率列（*_front_ratio 八列）**
- **基准语义**：本地 front 以**库内最新日重锚**（ratio 末端→1.000000，见 600971 第二跳变）；历史价按比率下调
- code 形态：**无后缀 6 位**（`'600971'`），与 wrapper 归一后一致 ⇒ 快照键直接复用
- **qfq_aux.db（11.6 GB）弃用**：两次全表探测均超时（count(*) 与元数据查询 >5min，冷盘），且代码链证明它不在取数路径 ⇒ kill 后台探测，快照源**改指 `stock_daily`**（更快更准）
