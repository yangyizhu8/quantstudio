## 3. 根因判定（与 L6 规则 `最新 eps>0` 联立）

1. **本地 L6 多剔的第一机理（本样本实证 ≥3 只/期）**：Q1 缺口使「最新行」回退到 2025 年报，年报为负的代码（301097/300313/300013）被本地剔除；平台有 Q1 行（或加权口径为正）→ 保留入选。观察值差 4~6 中至少 3 只由此闭环，余量在未入选样本内同机理。
2. **Q1 缺口横跨两表**：fin_indicator 与 income_statement 同缺（B 节 2 处期间错位即此）→ 属**数据管线层缺口**，正是 **P-A3 二期（fin_indicator EPS 回填）的目标范围**——本巡检给出实证样本清单，全池缺口扫描建议并入 P-A3 二期验收。
3. **eps→basic_eps 映射安全（C2① 实施依据）**：本地 fin_indicator.eps == income_statement.basic_eps（同期 14/14 一致）+ 探针三平台 basic_eps == 本地 eps（Δ=0.0000）→ 三方闭环，映射只译列名不代理语义成立。
4. **仅平台 16 只的缺口定性**：基本面全有、行情全无 → 本地 L0 即不可见。与 fall_reversal 07-01 ptrade 撤单 4 只（600193/600608/605081/688121 ⊂ 该 16 只）互洽：平台宇宙含它们（当日 volume=0 撤单），本地根本看不到 → 两端 top-18 名单必然分叉。300214（CANSLIM ptrade 07-28 买入）同属此集。
