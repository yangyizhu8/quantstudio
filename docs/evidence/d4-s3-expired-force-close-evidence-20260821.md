## 2. 强平语义规格（引擎对齐输入）

1. **触发**：持仓标的达到平台退市日（`is expired`，日志 DEBUG 于当日 15:30 打印）；
2. **价格**：**退市日当日收盘价（last price）**，非最后成交价、非均价、非下一交易日价；
3. **落账**：强平现金于**次一交易日**到账（T 日 expired，T+1 cash 生效）；
4. **数量**：全额持仓强平；
5. **同日多笔强平**：现金合并落账（07-14 两笔合计 +7300），单笔价格仍按各自当日 last。

## 3. 与本地引擎行为差异（D4-S3 根因实锤）

- 本地 stock_daily 该 4 码 K 线持续至 2026-07-31（000004 0.46 / 002808 0.21 / 002898 0.38 / 300029 0.14），期间无退市强平事件；
- 本地无权威摘牌日（stock_basic.delist_date 全 NULL；strategy_events 仅 first_cover）→ 引擎无法定位退市触发日；
- 本地行为 = 持仓至月末按末值估值；PTrade 行为 = 退市日按当日 last 强平、T+1 现金入账。价格值差异小（退市日 vs 月末收盘接近），但持仓/现金/换手口径与事件驱动路径完全不同。

## 4. 引擎对齐的前提与方案要点（供 D4-S3 立项）

- 数据前提：补权威摘牌日事件（stock_basic.delist_date 回填 / strategy_events 新增 delist 事件），当前缺口；本地 K 线延续至月末不能作为退市判据（退市整理期 K 线存在）；
