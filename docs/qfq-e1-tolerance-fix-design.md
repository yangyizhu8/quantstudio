## 1. 背景与动机

### 1.1 现象（生产 + 取证双证）

B 观察期首读 `factor_equivalent=0 blocked=31 放行率=0.0%`，拒绝原因一律为
`cross_column_inconsistent(high)`（E1 跨列标量一致判据，容差 **1e-9 相对**）。

ρ 取证（2026-10-22 夜，离线分片 × 库快照，三码全历史 1min）：

| 码 | join 行 | ρ 四列 median | \|ρ_high/ρ_open−1\| median | p95 | max |
|---|---|---|---|---|---|
| 000726 | 55,902 | 全 = 1 | **0** | 3.30e-05 | 1.63e-03 |
| 000729 | 55,902 | 全 = 1 | **0** | 2.73e-05 | 9.81e-04 |
| 000563 | 56,625 | median 1；p95 = 1.0011 | **0** | 2.36e-04 | 2.88e-03 |

### 1.2 直接原因

分钟价格 2–3 位小数，`raw ↔ qfq` 往返（÷af_i ×af_latest 再反向）放大末位误差到
**1e-5~1e-3 相对量级**；而 E1 要求四列比值一致到 **1e-9** ⇒ 几乎每个不一致 bar 都失败。

### 1.3 业务边界问题

`1e-9` 是**日线级**精度假设（日线价格 2 位小数、因子日频、往返一次）。分钟级复权往返的
数值精度天然低 3~6 个数量级；把日线阈值套到分钟，属**判据与数据粒度不匹配**。

### 1.4 潜在隐性风险（本方案必须一并处置）

若只把容差放大到 1e-3，会把 000563 那类 **+0.113% 的系统性整段偏移**一并放行（H3）——
那是真实的锚差异，不是精度噪声。故修正必须**同时**加"整段偏移"判别。

## 3. 任务拆解

### 3.1 实现要点

**E1′（tick 归一容差）**：对每列 c，
```
tol_c(t) = max( _FACTOR_EQUIV_COL_TOL_FLOOR, tick(asset_type) / price_ref_c(t) )
accept  若 |ρ_c(t) − ρ_base(t)| ≤ tol_c(t) · |ρ_base(t)| + 1e-15
```
- `tick`：STOCK `0.01`、ETF `0.001`（复用 `_raw_match_eps_minute` 的资产路由口径）；
- `price_ref_c(t)`：该 bar 库内该列价格（>0 保证）；避免除零用 `max(price, tick)`；
- `_FACTOR_EQUIV_COL_TOL_FLOOR = 1e-9`（保持日线严格下限，零回归）。

**E5（整段系统性偏移检测）**：仅当 E1′ 通过后执行。
```
对每个不一致 bar 计算 Δρ(t) = ρ_c(t)/ρ_base(t) − 1（各非基准列取均值）
按交易日分组，对每个交易日/连续段：
    m = median(Δρ)，s = std(Δρ)
    若 |m| > 3 · tick/price_median 且 s ≤ 0.25·|m| 且 n_seg ≥ 30
        ⇒ 判为「整段系统性偏移」→ 不放行（reason=ratio_segment_offset，报段区间与 |m|）
```
物理判据：**舍入噪声逐 bar 不同步（s 大或 m≈0）；锚差异段内同向同幅（|m| 显著且 s 小）**。
000563 的 +0.113%（≈1.13e-3）满足 `|m| > 3×tick/price`（若价格 10 元，3e-3？——**待 ②审核**：
阈值倍数需按实测 000563 的段内 m 与 s 定，方案附初值 `3×`，允许 ②审改 2×~5×）。

## 4. 风险描述

| 风险 | 说明 | 规避 |
|---|---|---|
| 容差过宽放行真损坏 | tick/price 在低价股（如 2 元）达 5e-3 | E5 兜底拦"整段同向"；E2/E3 拦"越界/突变" |
| E5 误杀正常因子漂移 | 若真实因子漂移也呈"段内同幅"（af 版本阶跃正是段内同幅！） | **关键风险**：需 ②审确认「E5 只拦**小幅度**（≤1e-2）整段偏移」，对 ≥1e-2 的段视为正常因子版本阶跃而放行 |
| 日线行为漂移 | 容差放宽影响日线 | `max(floor, tick/price)` + 日线实测差为 0 + A50 逐位不变 |
| 性能 | 新增按日分组统计 | 仅在**已判定不一致**行上做（毫秒级）；不影响正常路径 |
