### 2.1 「一字板」与「零开板」的严格区分（修正 v2）

| 概念 | 判据 | 与源的关系 |
| --- | --- | --- |
| **一字板** | 当日 `low == limit_price`（最低价即涨停价 ⇒ 全天未低于涨停） | 源 **`cond3` 正是要排除它**（`low < limit_price` 才通过） |
| **全天零开板** | `open_times == 0`（封板后未被打开过） | **源完全未使用 `open_times`**，**不构成任何条件** |
| **二者关系** | **不等价**：一字板必然是零开板，但**零开板不一定是一字板**（可开盘后快速封板、盘中从未打开，`low` 仍可能低于涨停价） | — |

> ⇒ **v2 把「非一字板」注释成「未开过板的」是错误的**：`cond3` 只判 `low < limit_price`，**不涉及开板次数**。

### 3.2 结论（**只到能证的一步**）

> **观测事实（仅此）**：同一交易日 `fd_amount` 与 `amount` 取值不同，`fd_amount` 约高两个数量级。
> **不得由此推断量纲、单位或口径**——数值差只说明「两者不是同一个量」。
> **`fd_amount` 的定义、单位、取样时点（收盘快照还是全天累计）、统计范围（含撤单与否）全部待核**（见 T1-T4）。
> **本稿不把 `fd_amount` 读作「已成交额」，也不断定它是「封单额」。**
> **其确切语义（封单额？申报口径？含撤单累计？）本稿不认定**，须向数据方或字段文档确认。

## 二十七、【v11】R450 量纲更正：s 系数表纠错 ＋ 价格口径前提 ＋ Q-3 精确候选

### 27.1 🔴 我原稿的 s 方向**算错了**（R450 关闭判据）

**正确推导**（设真实成交额 A 元、真实成交量 V 股，VWAP = A/V 元/股）：

```
记录值： amount_rec = A / u_a   （u_a = 该单位含多少元：元=1，千元=1000）
         vol_rec    = V / u_v   （u_v = 该单位含多少股：股=1，手=100）

amount_rec / vol_rec = (A/u_a) / (V/u_v) = (A/V) × (u_v/u_a) = VWAP × s

⇒ k = (amount_rec / vol_rec) / close = s × VWAP / close
```

**s = u_v / u_a 系数表**：

| amount 单位 | vol 单位 | u_a | u_v | **s = u_v/u_a** |
| --- | --- | --- | --- | --- |
| 元 | 股 | 1 | 1 | **1** |
| 千元 | 手 | 1000 | 100 | **0.1** |
| 元 | 手 | 1 | 100 | **100** |
| 千元 | 股 | 1000 | 1 | **0.001** |

**⇒ 与我 v10 所写对照**：

| 组合 | **正确 s** | **我 v10 写的** | 判定 |
| --- | --- | --- | --- |
| (元, 股) | **1** | 1 | ✅ 对 |
| (千元, 手) | **0.1** | **10** | 🔴 **差 100 倍，方向错** |
| (元, 手) | **100** | 100 | ✅ 对 |
| (千元, 股) | **0.001** | **1000** | 🔴 **差 10⁶ 倍，方向错** |

> **错误性质**：我把 `u_a/u_v`（反向）当成了 `u_v/u_a`。**这是纯算术方向错误，不是判别力问题**——R450 退回正确。
> **更正后四值间距**：0.001 / 0.1 / 1 / 100 —— **相邻差 10~100 倍，判别力充足**。

### 27.2 🔴 价格口径前提：**VWAP 不恒等 close**（R450 指出）

**k 的完整形式**：

```
k = s × VWAP_true / close_rec
```

**要由 k 反解 s，必须 `VWAP_true / close_rec ≈ 1`**。该比值成立需**两个前提同时满足**：

| # | 前提 | 若不成立 |
| --- | --- | --- |
| **P1** | `close_rec` 与 `amount/vol` **同为原始（未复权）口径** | 若 close 为复权价而成交额量为原始，则 `close_rec = close_orig × f`，得 `k = (s/f) × VWAP_orig/close_orig` ⇒ **s 与 f 不可分离，无法判定** |
| **P2** | 当日 `VWAP_true` 与 `close_rec` **量级相近** | VWAP 是全日加权均价，通常落在 close 附近（±若干%），**但不等同**——涨跌停/大幅波动日可偏离 |

**已实读的关键事实（fb 脚本 L31）**：

> 「本库 `stock_daily` 的 **is_qfq 全为 True（前复权）**」

**⇒ 这意味着 P1 默认不成立**——除非满足下述条件：

| 情形 | f | P1 是否成立 |
| --- | --- | --- |
| **取该表 max(trade_date)（最新交易日）** | **f = 1**（前复权以最新价为锚，最新日价格＝原始价） | ✅ **成立** |
| 取历史日（其后发生过除权） | f ≠ 1 | ❌ **不成立** |
| 表更新后该日不再是锚点（其后新增除权） | f ≠ 1 | ❌ **不成立** |

> **⇒ 增加前提 P3：「取样日必须该表 max(trade_date)，且此后无除权事件」**。
> **若无法确认 P3 成立 ⇒ 判为「未判定」**，不得强行读数。

### 27.3 可验证区间判据（**替代「k≈常数」的裸比法**）

> R450：「用同日原始 high／low 或可靠绝对单位链建立**可验证区间**及**未判出口**」。

### 28.2 🔴 修正二：`min(close,pre_close)×0.95` **不是已证 VWAP 下界**（R451 反例成立）

**R451 反例（我验证其成立）**：

```
设 开=收=pre_close=10.00（元），盘中最低 8.00，且 8.00 处成交占绝大部分
⇒ VWAP = Σ(价×量)/Σ量 ≈ 8.2
而我原式下界 = min(10.00,10.00) × 0.95 = 9.50
⇒ VWAP(8.2) < 下界(9.50)  —— 反例成立，该式不是下界
```

**错误性质**：VWAP 是**全日成交量加权均价**，权重集中在**低价放量时段**时，**可以远低于 close 与 pre_close**。
用 `min(close,pre_close)` 作下界，**隐含假设「均价不低于两价之较低者」——该假设无依据**。

**⇒ 有效 VWAP 区间只有一种可靠形式**：**同日 `[low, high]`（同口径）**。
> 因 `VWAP = Σ(价×量)/Σ量`，各项价格 ∈ [low, high] ⇒ **VWAP 必 ∈ [low, high]**（数学上成立，无需额外假设）。
> **其余任何由 close/pre_close 派生的「保守区间」均不成立**，本稿**不再使用**。

**⇒ 处置**：**降级区间作废**。当前**无有效区间**（因 `low` 未证存在），**区间判据不可执行**。

| **输出** | **ŝ = s_true**（唯一定论）；或无通过者 ⇒ **未判定** |
| **为何至多一个通过** | 候选间距 ≥ **10×**；而 `[lo,hi]` 宽度比 `hi/lo` 为**日内振幅**（典型 <1.2）；`A/s` 随 s 反比放大 ⇒ **四候选的检验值彼此至少差 10×，不可能同时落入一个宽度 <1.2× 的区间** |
| **不可判出口** | ①**0 个**通过 ⇒ 未判定（数据或前提不符，**不选最接近**）②**≥2 个**通过 ⇒ 数据自相矛盾，未判定 ③`lo`/`hi` 空或非正 ⇒ 未判定 ④`f≠1` ⇒ **本判据不适用**（见 §33.4） |
| **前提** | `f=1`（该行未复权），**这是强判据唯一的软肋** |

### 33.4 🔴 UNKNOWN 分支：f 完全未知时，`ŝ` **不等于** `s_true`

**代数事实**（可直接推导，不含假设）：

```
真实约束： lo/f ≤ A/s_true ≤ hi/f     （原价区间）
等价于  ： A / (s_true / f) ∈ [lo, hi]
⇒ 检验实际测到的是  ŝ = s_true / f    （不是 s_true）
```

**⇒ 区间法测的是 `s/f`，不是 `s`。f 未知时，s 与 f 不可分离。**

**歧义集（`f ≤ 1` ⇒ `f = ŝ/s_true ≤ 1` ⇒ `s_true ≥ ŝ`）**：

| 观测到的 ŝ | **f 完全未知时**，`s_true` 可能取值 | **候选个数** |
| --- | --- | --- |
| **100** | {100} | **1（唯一可判）** |
| **1** | {1, 100} | **2** |
| **0.1** | {0.1, 1, 100} | **3** |
| **0.001** | {0.001, 0.1, 1, 100} | **4 ⇒ 判别力为零** |

> **⇒ 我方明确承认**：**f 完全未知时，`ŝ=0.001` 与 `ŝ=0.1` 两种观测几乎不能定单位**；
> **不能只说「判别力不为零」**——**最坏情形（ŝ=0.001）判别力恰为零**：四个候选全部「可由某个 f∈(0,1] 解释」。
> 这正是 R456 要求的「**不能排除通过缩放解释的候选**」，此处以**枚举**形式给出，不再含糊。

### 33.5 🔴 有界分支：**f > 0.1 ⇒ 四种观测全部唯一可判**（可证）

设已知下界 **f > ρ**。由 `f = ŝ/s_true` ⇒ `s_true < ŝ/ρ`。

**取 ρ = 0.1**：

| ŝ | 约束 `s_true < 10·ŝ` | 候选中满足者 | 结果 |
| --- | --- | --- | --- |
| 0.001 | `s_true < 0.01` | {0.001} | ✅ **唯一** |
| 0.1 | `s_true < 1` | {0.1} | ✅ **唯一** |
| 1 | `s_true < 10` | {1} | ✅ **唯一** |
| 100 | `s_true < 1000` | {100} | ✅ **唯一** |

> **⇒ 判据（弱分支的核心）**：**只要该行复权缩放 f > 0.1（即当日因子不低于最新因子的 1/10），区间法即恢复为唯一判定。**
> **反之**：若 `0 < f ≤ 0.1`（累计复权超过 10 倍），则按 §33.4 出现多候选，**必须记未判定**。

**ρ 取值的敏感性（供裁）**：

| ρ | 唯一可判？ | 说明 |
| --- | --- | --- |
| 0.1 | ✅ 四种全唯一 | **最省假设即可恢复判别力** |
| 0.01 | ⚠️ ŝ=0.1 与 ŝ=1 各剩 2 候选 | 更弱假设，判别力下降 |
| 0 | （=完全未知） | 见 §33.4 |

### 33.6 纸面算例（**数值为示意，非实测；仅验算术**）

> 假设某行观测：`lo = 10.00`、`hi = 10.50`（宽度比 1.05），并设 `A = a/v` 如列。

**算例一（ŝ=1）**：设 `A = 10.16`

| s | `A/s` | 是否 ∈ [10.00, 10.50] |
| --- | --- | --- |
| 1 | **10.16** | ✅ **通过** |
| 0.1 | 101.60 | ❌ |
| 0.001 | 10,160 | ❌ |

**算例二（ŝ=0.001）**：设 `A = 0.01016`

| s | `A/s` | 是否 ∈ [10.00, 10.50] |
| --- | --- | --- |
| 0.001 | **10.16** | ✅ **通过** |
| 0.1 | 0.1016 | ❌ |
| 1 | 0.01016 | ❌ |
| 100 | 0.0001016 | ❌ |

⇒ `ŝ = 0.001`。**f 未知 ⇒ 4 候选全部可能（判别力 0）**；**f > 0.1 ⇒ 唯一为 `s_true = 0.001`（千元,股）**。

**算例三（不可判出口）**：设 `A = 50`、`[10.00, 10.50]`

⇒ **0 个通过 ⇒ 未判定**（**不得**取「最接近的 1」）。此即 §33.3 的出口①。

### 33.8 `f > 0.1` 的旁证强度（**弱，仅限近期行**）

| 证据 | 读数 | 能说明什么 | **不能**说明什么 |
| --- | --- | --- | --- |
| 11-16 运行的单次因子修订幅度 | `601881.SH` 比率 **0.986983**；`603273.SH` **0.998619** | **单次修订仅 1~2%** | 不能说明**累计** f |
| 系统自设合理带 | `[0.7, 1.3]`，超带判异常并**阻断写入** | 系统认为**单次**超出 ±30% 已属不可信 | 累计 f 可远低于 0.7（长期分红送转） |

> **⇒ 结论**：`f > 0.1` 对**近期行**（如 1 年内、无大额送转）**很可能成立**；**对早期历史行不成立的概率显著上升**。

### 33.10 对旧源复刻的影响（**逐分支**）

| 判定结果 | 对 `trading-battle-back` fb 源（按「vol=手、amount=千元」处理）的影响 |
| --- | --- |
| `s_true = 0.1`（千元,手） | ✅ **fb 注释正确**，其 ×100/×1000 换算成立 |
| `s_true = 1`（元,股） | 🔴 **fb 有量纲偏差**：`vol` 实为股却当手再 ×100 ⇒ 成交量**放大 100×**；`amount` 实为元却当千元 ×1000 ⇒ **放大 1000×**。⇒ `seal_ratio = bid_vol/volume` 的**分母放大 100×** ⇒ **封单比整体缩小约 100× ⇒ 恒低于 5% 下限 ⇒ 恒不命中**（此推论依赖 fb 实际取用路径，**未逐行核**） |
| `s_true = 100`（元,手） | 🔴 `vol` 当手**正确**；`amount` 当千元 **错 1000×** ⇒ 凡用 `amount` 的条件（均价类）**失真 1000×** |
| `s_true = 0.001`（千元,股） | 🔴 `vol` 当手 **错 100×**；`amount` 当千元**正确** |
| **未判定** | **不得据此改动旧源**；维持现状并登记未知 |

> **⇒ 影响面结论**：**四分支中有三支会指向「fb 源存在量纲偏差」**。若最终判定为 `s_true = 1`（元,股），则 **fb 的封单比判据在当前数据面上结构性失效**——**这是本议题最高风险项**，须在 G2 前明确。
