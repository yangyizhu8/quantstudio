## 二、四术语逐项（**区分三层**）

### 2.1 命中（hit）

| 层 | 内容 |
| --- | --- |
| **既有源码规则** | 源码**无「hit」变量**。最接近的是 `cond1`（涨停价）与 `_state` 转移。**「命中」是实现层概念，源码未显式定义** |
| **用户目标待确认** | 同 U1；以及「命中」是否等于「买入信号触发」 |
| **新候选** | 日频版：`limit_list_d.limit_type=U` 或 `limit_list_ths.status ∈ {换手板,一字板,T字板}` |
| **时点** | 源码 = **每 tick**（盘中）；日频候选 = **T+1** ⇒ **粒度降级** |
| **缺失处理** | 日频表缺日 ⇒ **不出件 + fail-closed**；tick 缺 ⇒ 源码 `continue`（L296/L299-300） |

### 2.2 封板

| 层 | 内容 |
| --- | --- |
| **既有源码规则** | **无「封板」独立判据**。`cond1` 要求 `current_price >= limit_price`；`cond2` 要求封单比 ∈[5%,30%]；`cond3` 要求**非一字板**（`low < limit_price`） |
| 🔴 **更正首稿** | 首稿称「要求 `open_times=0`（全天零开板）」——**源码无此要求**。`open_times` 是 `limit_list_d` 的日频字段，**源码完全没用它**。**且源码 `cond3` 明确排除一字板**（未开过板的），与首稿「要求零开板」**方向相反** |
| **用户目标待确认** | U2／U3／U4 |
| **新候选** | 日频近似：`close == stk_limit.up_limit`（精确价可得）＋ `limit_list_ths.status` 形态标签 |
| **时点** | `up_limit` **盘前已知**；封单比所需 `bidVol[0]` **盘中每 tick** |
| **关键约束** | **收盘封板不要求全天零开板**（源码 `open_times` 未被使用；`cond3` 只排除「一字到收盘」的形态） |

### 2.3 炸板回封

| 层 | 内容 |
| --- | --- |
| **既有源码规则** | **无「炸板回封」概念**。仅有**撤单条件 L438**：持仓后封单量较峰值降 ≥20% ⇒ 撤单 |
| **用户目标待确认** | U4 |
| **新候选** | `limit_list_d.open_times > 0` ＋ `last_time` 晚于 `first_time`；或 `limit_list_ths.first_ld_time`/`last_ld_time` |

| **缺失处理** | `open_times` 为 NULL ⇒ **视为未知**（不判为 0）；**日频只能表达「发生过」，不能表达「第几根 bar」** |

## 三、tick 字段可得性（**五表有数据 ≠ tick 消费字段可得**）

| 源字段（L335-341） | 需求时点 | 本地可得 | 可用替代 | 差异性质 |
| --- | --- | --- | --- | --- |
| `stockCode` | 每 tick | ✅ | — | 无差异 |
| `preClose` | 每 tick | ✅ 分钟/日线 `pre_close` | — | 时点可满足 |
| `lastPrice` | 每 tick | ✅ 分钟 `close`／日线 `close` | 粒度降级 | **tick→分钟/日线** |
| `low` | 盘中累计 | ✅ 分钟 `low` | **须跨分钟累计** | 口径差异 |
| `volume`（当日累计） | 盘中累计 | ✅ 分钟 `vol` 求和 | **须核含竞价/复权** | 口径差异 |
| 🔴 **`bidVol[5]`** | **每 tick** | ❌ **零源** | **无等价替代** | **结构性缺口** |

> **决定性**：`seal_ratio = bid_vol[0]/volume`（L352）的分子**无本地来源**。
> **日频 `amount`/`volume` 是「已成交」，`bid_vol` 是「未成交挂单」——不是精度差，是量纲相反。**
> ⇒ **五张日频表无论多全，都不能提供 `bidVol`。**
