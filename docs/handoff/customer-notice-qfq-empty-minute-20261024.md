## 一、问题原因（客户可读）

您当前**只启用了日线采集、未下载分钟线**（分钟表为空）。系统在计算每只票「重锚价格区间」时，把空分钟表读成了 `1970-01-01` 的区间，随后被一致性守卫判为「非法窗口」，于是**跳过该票的重锚**。全部标的都这样 ⇒ 本轮 **0 个单元完成** ⇒ **水位线不提交**。

**这是框架缺陷，不是您的操作错误**——「只下日线」是合法配置。已定位根因并修复。

## 二、修复内容（客户可读）

1. **空表语义修正**：分钟表无数据时不再被当作「非法区间」，而按「该表无事可做」处理；
2. **采集层**：分钟区间为空时**跳过分钟采集**（不再发起 1970 窗口请求）；登记记录中分钟区间**留空**（不写 0 伪数据）；
3. **重锚引擎**：新增「无分钟段」模式——**默认关闭**、仅在确认分钟表为空时开启；只按日线完成重锚并提交。事件审计显式标注「无分钟段」，**可区分「无分钟段」与「分钟已重锚 0 行」**；
4. **补录登记**：分钟表为空时**不再写入 1970 区间的待补录行**。

**兼容性**：有分钟数据的环境**逐位不变**；未显式开启时空分钟仍按原样硬失败（防误用）。

**生产实证（修复方环境，2026-10-26）**：空分钟证券触发新路径 **20 次，零崩溃**；**7 只空分钟证券全部完成日线重锚并提交**（000022/000023/000040/000043/000046/164808/508008），事件审计均带「无分钟段」标记。
