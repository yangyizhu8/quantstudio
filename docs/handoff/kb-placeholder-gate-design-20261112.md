## 2 规则定义

### 2.0 作用域（R4 第④条第一半：正文引用与字段假填分开）

**本门只检查字段值，绝不扫描正文（`## 详情` 及 front-matter 之外的内容）。**

| 对象 | 是否受检 | 理由 |
|---|---|---|
| `trigger` 字段值 | **是** | 开案命中依赖它 |
| `feedback.{contract_row,gate_rule,template_patch}` 值 | **是** | 回哺三通路的登记质量 |
| 正文任意段落 | **否** | 条目正文**可以也应当**讨论"占位"（如 OPS-2026-0003 的主题即是占位危害）；扫正文必然误伤 |
| 其它六必填字段（symptom/root_cause/…） | **否（本门不管）** | 既有「非空」判据维持；是否纳入由独立审另行裁定（不在本稿范围） |

### 2.1 占位词表（唯一判定源）

```python
PLACEHOLDER_TOKENS = ("待补充", "待填", "TODO", "TBD", "FIXME", "placeholder", "占位")
```

- 匹配：`casefold()` 后子串命中即判占位；**不看长度**。
- 空值/`null`/`None` 字面量由既有「为空」判据处理，不归本门。

### 2.2 `trigger` 两段式（R4 第③条：兼容半角）

**语法**：

```
trigger := <复现条件> <分隔符> "问法" <冒号> <口头问法>
分隔符   := "；" | ";"            # 全角或半角（R4 修订：兼容，不一刀切）
冒号     := "：" | ":"
```

机检判据（T1–T4 全满足）：

| # | 判据 | 实现 |
|---|---|---|
| T1 | 存在分隔符 | `re.search(r"[；;]", value)` |
| T2 | 分隔符后（允许空白）紧跟 `问法` + 冒号 | `re.search(r"[；;]\s*问法[：:]", value)` |
| T3 | 问法段 `strip()` 后 ≥4 字 | 截取后段计长 |
| T4 | 两段均不含占位词 | `not is_placeholder(each_half)` |

**规范化建议（非强制）**：新条目用**全角 `；`**（与人读中文排版一致）；既有半角**不阻断**、不改写。
**迁移影响**：**零** —— 兼容后既有 29 条两段式（全角）继续 PASS；半角写法也 PASS，不产生任何历史改写动作。
（v1 曾定「全角唯一合法」，R4 指出无必要语义依据，本稿已撤。）

### 2.3 `feedback` 三键

| # | 判据 |
|---|---|
| F1 | 三键中**至少一项**满足「非空 且 非占位 且 非 `null`/`None` 字面量」 |
| F2 | **任何被填写（非空）的键不得是占位串**——"假填"比"留 null"更差，直接不合格 |

- 保留 `null` 为合法声明（"该通路无回哺"），只打假填。

## 3 阶段·路径·标记（R4 第①条：打破循环定义）

### 3.1 判据（纯路径/标记，**不引用本门自身结论**）

| 态 | 可机判条件（`AND` 全满足） | 说明 |
|---|---|---|
| **条目件（正式态）** | ①路径匹配族 `entry_glob`；②位于 `knowledge/<族>/` 下；③basename 匹配族 `id_pattern` | 纯路径判据，与"是否通过机检"无关 ⇒ **无循环** |
| **草稿态** | 以下任一：①路径不匹配上述三条（如 `docs/drafts/`、`tmp/`、`--out` 任意值）；②basename 含 `.draft.`（如 `OPS-2026-0100.draft.md`）；③front-matter 显式 `stage: draft` | 显式标记 ≥ 路径推定（**标记优先**） |
| **非条目件** | 不匹配 `id_pattern`（如 `README.md`、`NOTES.md`） | 既有 `non-entry-file` skip 已覆盖，本门不参与 |

**默认兼容**：无 `stage` 标记 + 落在族目录 + 匹配 `id_pattern` ⇒ **判为正式态**（维持既有语义，不加新字段也能机判）。`stage` 为**可选字段**，不进入任何族的 `required_fields`（不构成契约变更）。

### 3.2 两态的行为差

| 态 | 占位检测 |
|---|---|
| 草稿态 | **允许**占位；`kb_draft.py` 生成时打印 `DRAFT: 含 N 处占位（正式落位前须补实）`，`--json` 输出 `placeholder_hits` |
| 正式态 | 按族 `placeholder_gate` 档位判（`off`/`warn`/`strict`），默认 `off` |

### 3.3 族级开关与边界（R4 第④条第二半）

```yaml
  - id: ops
    placeholder_gate: off            # off | warn | strict（默认 off）
    placeholder_gate_since: null
```

- **`off` 的语义边界（写死）**：`off` **只关闭本门（占位检测）**，**绝不关闭任何既有判据**——六必填、`fix_layer` 枚举、`domain` 词表、`recurrence` 整数、`feedback 非空`、`status` 词表**照常生效**。
- 机检断言（§6.3 的 OFF1/OFF2）：单族 `off` 时，构造"缺 `root_cause`"／"`fix_layer` 越界"的条目仍必须 FAIL ⇒ 证明原必填未被关掉。

## 4 历史存量冻结（R4 第②条：指纹／报警／边界／清理记录）

### 4.1 登记结构

```json
{
  "schema": 1,
  "registered_at": "2026-11-13T00:00:00+08:00",
  "entries": {
    "knowledge/db/DB-2026-0001.md": {
      "sha256": "<该文件 front-matter 全文 sha256>",
      "fields": ["trigger", "feedback.contract_row"],
      "placeholder_snapshot": {"trigger": "待补充：最小复现触发条件（一句话可判定是否命中）", "feedback.contract_row": "待补充：…"},
      "owner": "<清理责任人>",
      "target_round": "R-20261231-01",
      "registered_at": "2026-11-13T00:00:00+08:00",
      "last_verified_at": "2026-11-13T00:00:00+08:00"
    }
  },
  "cleanup_log": [
    {"at": "…", "file": "…", "action": "cleaned|renewed|dropped", "by": "…", "evidence": "…"}
  ]
}
```

### 4.2 判定（四条，缺一即失效）

| # | 规则 |
|---|---|
| **G1 内容指纹** | `sha256` 为**主判据**（禁用 mtime 作可用性判据）；指纹一致 ⇒ 该文件的**已登记占位**计 `grandfathered`，仅打印不 FAIL。 |
| **G2 变异报警** | 指纹**不一致** ⇒ 立即 `PLACEHOLDER_REGISTRATION_STALE`（strict 档 FAIL）——内容被改过就必须重新核对：要么占位已清（应从登记表删除），要么改得更差（应报）。**禁止静默沿用旧登记**。 |
| **G3 边界** | 登记**只覆盖 `fields` 列出的字段**（逐字段登记）。同文件其它字段出现占位 ⇒ **照常 FAIL**（不因整文件登记而整文件豁免）。新增文件永不自动纳入。 |
| **G4 清理记录** | 每条登记必带 `owner` + `target_round`；`cleanup_log` 记录 `cleaned/renewed/dropped`。**未设 `target_round` 的登记不被接受**（防"设了就不管"）。 |

### 4.3 防「永久白名单」

| 机制 | 规则 |
|---|---|
| **过期告警** | `last_verified_at` 超 **30 天**未复核 ⇒ `PLACEHOLDER_REGISTRATION_EXPIRED`（warn 档打印，strict 档 FAIL） |
| **续期留痕** | 续期须写 `cleanup_log` 的 `renewed`（含理由），不得静默刷新时间戳 |
| **收缩不扩张** | 清理后登记条目**只减不增**；新增登记须独立审（不接受"运行时自动新增登记"） |
| **数量闸** | 任一族登记件数 **> 该族条目 50%** ⇒ `PLACEHOLDER_BACKLOG_MAJOR`（该族等于半个库空壳，须单独立项而非冻结了事）——db 现状 42/44≈95%，**故 db 必须"单独立项清理"而非冻结后不管** |
