# 探针策略使用说明（PD-0019 F1 判定 · 2026-11-10）

> **文件**：`probe_override.py`（同目录，约 60 行，含注释）

> **用途**：判定 F1（P0-1 虚拟持仓未生效）根因是 **P-a 贴装文件不一致** 还是 **P-b 平台代码变换**
