### 问 1：§2.4.12 的逐行口径是否认可？特别是 H6 的「已测一半 / 未测一半」切分

- **我方做法**：把 H6 拆成两半——「采集 + 比较链」记为**已实测**（U18 7/7、U26 8/8），「跨环境复制后的三值同源」记为**未测**（U16/U17）。
- **理由**：U18/U26 测的是**同一份 pin 的采集与比较**，不是「复制解释器环境后 source_id 仍相符」；后者需要复制环境，本轮边界禁。
- **若否决**：可整组降级为「未实测」，但会**低估**已有证据（把一个真跑过 7+8 条断言的链路写成 0）。
- **我方倾向**：保留拆分，且在表内**已写明两条覆盖范围**，不冒充全组。

### 问 2：§六「不作承诺」措辞是否足以免责？

- **我方做法**：显式否定式（「不承诺」「不构成任何保证」）+ 指明数据来源局限（合成库 / 设计推理）+ 给出降级路径（§2.4.7）。
