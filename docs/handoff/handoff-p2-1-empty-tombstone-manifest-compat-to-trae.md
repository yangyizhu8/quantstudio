## 一、拟插入的结构（请据此判定）

**位置**：与既有 ckey 条目**同命名空间**（同一 `manifest[table][ckey]` 字典），不新增顶层键。

```jsonc
{
  "<table>": {
    "<ckey 例如 etf_minutes|1970-01-01|1970-01-02>": {
      // ↓↓↓ 既有字段（既有写入路径，逐字不变）
      "job_id": "export",
      "shards": ["s1", "s2"],
      "shard_sizes": {"s1": 123, "s2": 456},
      "bytes": 579,
      "rows": 10,
      "ts": "2026-09-25T10:00:00",
      // ↓↓↓ P2-1 拟新增（**仅在确认为空窗时写入**）
      "empty": true,
      "empty_ts": "2026-09-25T10:00:00",
      "empty_ttl_s": 604800            // 默认 7 天，可配 QS_EXPORT_EMPTY_TTL_S
    }
  }
}
```

**语义**：
- 写入时机：`export_dataset` 返回 **0 shards / rows=0**（既有空窗形态）时；
- 命中：`entry.get("empty") is True` 且 `now - empty_ts < empty_ttl_s` → **跳过 export**，
  按既有空语义返回空结果（`frames=[]`），**不调用** `_resolve_shard_paths`；
- 过期：`empty_ts + ttl <= now` → 视为 miss，正常重取；重取仍空 → 刷新 `empty_ts`；
- 一致性命门：命中/未命中两条路径的**返回值逐值一致**（纯性能型判据）。
