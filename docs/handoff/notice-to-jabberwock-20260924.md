**重要（请知悉）**：
- 此问题**不会损坏数据**——属于「读取环节的防御缺失」，已入库数据完整可用；
- **重启程序仍会撞上**（不是重启能解决的）；
- 更新到修复版本后即可解决。

**更新 4 步**（先**停止采集程序**；PowerShell 中执行）：

```powershell
cd D:\hasym\PycharmProjects\QuantStudio
git pull origin main
git log --oneline -1        # 应显示【SHA】（含本次修复）
# 然后重新启动采集程序，观察一个完整采集周期
```

**更新后核对 3 项**
1. 采集周期**正常跑完**，不再出现「停摆/重锚环」；
2. 日志中**不再出现 `IndexError`**；
3. 若日志出现 `export_cache 重取无 shard（ckey=…）：本批降级为空、不写 manifest，周期继续` —— 这是**修复后的正常降级**（该窗口确无产出，程序继续跑并在下个周期自然重试），**不是故障**；如方便可把该行回传我们备案。
