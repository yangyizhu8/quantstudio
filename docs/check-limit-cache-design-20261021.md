### 1.2 缺陷点

`check_limit`（`ptrade_api.py:1181`）每次调用执行**一次全 universe 日线区间查询**：
```python
# ptrade_api.py:1210-1212（唯一 DB 调用；其余为纯计算）
bars = self._market.get_bars(bare_codes, qd_text, qd_text,
                            fields=["close", "preClose", "high", "low"], fq=None, frequency="1d")
```
策略每日调用 **2 次**（`query_date=T-1` 与 `T-2`）⇒ **82.65 s/日 / 83% of 池构建** ✗

### 1.3 重复计算事实（缓存收益来源）

串行多日回测的日期访问模式：

| 回测日 | 查询日期 | 是否与前日重复 |
| --- | --- | --- |
| D | D-1, D-2 | — |
| D+1 | D, **D-1** | **D-1 已在第 D 日算过** ✓ |
| D+2 | D+1, **D** | **D 已在第 D+1 日算过** ✓ |

⇒ 稳态下**每日 2 次查询中有 1 次命中**（50%）⇒ 预期节省 **≈41 s/日**

⚠ **不夸大**：另一 41 s 是最新日期（首次访问），**无法通过本缓存消除**（无更早计算可复用）。
理论更高收益需「两日期合并单查询」（变更 API 内部取数形态），列为**阶段二候选**（见 §六），不在本方案内。

## 三、必含三件（用户指定）

### 3.1 LRU 上限与淘汰策略（申报）

| 项 | 设计 |
| --- | --- |
| 缓存结构 | `{qd_text: {bare_code: state_int}}` —— **按日期分桶** |
| 键 | `(qd_text, bare_code)` |
| 值 | `int`（1/-1/2/-2/0，与现值同类型 ✓） |
| **容量** | 保留**最近 N 个日期桶**，`N = QS_LIMIT_CACHE_DATES`（默认 **8**） |
| **淘汰** | **FIFO 按日期桶**（回测日期单调递增 ⇒ 最老桶最先淘汰，与访问局部性一致 ✓）；桶内不淘汰 |
| 内存估算 | 8 桶 × 3,181 码 ≈ **25,448 条**；每条（tuple key + int）≈ 200 B ⇒ **≈5.1 MB** ✓（对比：全 148 日不淘汰 = 470,788 条 ≈ 94 MB ✗ 故必须设上限） |
| 关闭开关 | `QS_LIMIT_CACHE_DATES=0` ⇒ **完全不缓存**（行为等同现状，用于回退与 A/B） |
| **诊断开关**（②审裁定①） | `QS_LIMIT_CACHE_DIAG=1` ⇒ **强制禁用缓存**（无视 DATES）并恢复逐码 `QS_DIAG` WARNING —— 排查涨跌停问题时须能拿回原诊断粒度 |
| 诊断汇总（②审裁定①） | 缓存启用时，命中分支**不逐码刷屏**，改为每日一行 `QS_DIAG {'kind':'LIMIT_CACHE_HIT', 'date':..., 'hit':N, 'miss':M}` 汇总计数 |
| **负向保留**（②审裁定①） | 缓存**关闭**或**未命中**路径的 WARNING 行为**逐位不变**（`LIMIT_CHECK_NO_ROW` / `NO_PRECLOSE` / `NO_HILO` / `NO_PREV_DAY` 全部照旧）⇒ 由 A1 硬门覆盖 |

### 3.2 按 run 隔离（跨回测实例不残留）

| 措施 | 说明 |
| --- | --- |
| **实例级属性** | 缓存挂在 `PtradeAPI` 实例上（`self._limit_cache`），**不设模块级全局** ⇒ 新回测实例 = 新 `PtradeAPI` = 空缓存 ✓ |
| **显式清空** | `initialize` 阶段调用 `clear_limit_cache()`（防御：同一实例被复用于二次回测时清空） |
| **验收断言** | ① 同进程连续两个 `PtradeAPI` 实例：实例 B 首次 `check_limit` 必须**未命中**（打点计数器验证）；② 同实例 `clear_limit_cache()` 后再调用必须未命中 ✓ |

### 3.3 回测期间日线不可变（论证）

| # | 证据 | 结论 |
| --- | --- | --- |
| 1 | `duckdb_data_access.py:197`：`self._ro_conn = _ddb.connect(str(self._db_path), read_only=True)` | **provider 以只读方式打开 DB** ⇒ 回测进程无法写入 ✓ |
