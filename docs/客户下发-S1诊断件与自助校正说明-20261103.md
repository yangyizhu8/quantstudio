# 客户下发材料 · QFQ 辅助库路由诊断与记录校正（S1 只读诊断 + S2 换代校正）

> 状态：**已按实现对齐**（命令名、参数、备份三档、审计字段均与程序一致）；下发前请确认 §6 的三个决策点
> 适用：出现 `AuxRouteError: source_generation='mcp-gen1' 的辅助库不存在: .../data/D:\...`
> 影响面：`stock_daily` / `etf_daily` / `stock_minutes` 三个增量任务（共用 mcp-gen1 路由）

---

## 1 现象与影响（先让客户看懂）

- 现象：这三个任务在**取数前**就失败，日志末尾是一屏 traceback；
- 原因：`qfq_source_cutover` 里有一条历史路由记录，其 `aux_db_path` 是本项目**迁移前机器**的
  Windows 绝对路径；在你的 macOS 上它被当成相对路径拼接，得到 `data/D:\...` 这种畸形路径；
- 影响：这三张表**停止更新**；其余 70 个任务不受影响。

## 2 S1 · 只读诊断（客户可自助，零写入）

命令（在项目根执行）：

```bash
qs-deliver cutover-diag                 # 人类可读
qs-deliver cutover-diag --json          # 机器可读报告（随工单回传我方）
# 如不在项目根：加 --data-root <项目>/data --config-dir <项目>/config
```

输出包含：

| 字段 | 含义 |
|---|---|
| `records[]` | 每条 cutover 记录：`cutover_id / price_source / source_generation / status / aux_db_path / migratable / reasons` |
| `migratable=false` | 该记录不可用：`reasons` 给出依据（异平台绝对路径 / 目标库不存在 / 值为空） |
| `suggested.aux_db_path` | 建议的新值（取自你本机 `qfq_aux_paths.json`，并校验是否存在） |
| `writes` | 恒为 `0`（零写入的机器证据） |

**纪律**：S1 只读 —— 不改库、不建文件、不停进程；报告可安全回传我方。

## 3 S2 · 换代校正（换代，不改行）

### 3.1 我方执行（默认路径，客户无需操作）

我方在约定窗口内执行：前置余量检查 → 备份 → CAS 校验 → 插新记录 + 旧记录 `status='superseded'`
→ 复验 → 审计行落盘。

### 3.2 客户自助（保留能力，需严格约束）

```bash
# ① 先看将做什么（默认 dry-run，只打印，不写任何东西）
qs-deliver cutover-rehost \
    --cutover-id <cutover_id> \
    --expect-aux-db-path "<库内现值，必须逐字一致>" \
    --new-aux-db-path "<本机建议值，取自 S1 的 suggested.aux_db_path>" \
    --authorization "<客户授权依据，如：邮件/工单号>"

# ② 确认无误后再真正执行
qs-deliver cutover-rehost ...（同上参数）--apply
```

约束（均为 fail-closed，**无任何强制跳过开关**）：

| 约束 | 行为 |
|---|---|
| 缺 `--apply` | 只打印方案，零写入 |
| `--expect-aux-db-path` 与库内现值不一致（CAS） | **拒跑，库零变化**，审计行记 `rejected` |
| `--authorization` 为空 | **拒跑**（授权依据是审计行必填项） |
| 磁盘余量不足 | **拒跑**并报"还差 X GiB"（无 force 通道） |
| 备份任一档失败 | **拒跑**（缺备份不做事） |

### 3.3 备份三档（执行前自动完成）

| 档 | 内容 | 作用 |
|---|---|---|
| **b（主，必做）** | 完整库副本 `quantstudio.db`(+`-wal`) | 整库还原手段 |
| **a（兜底，可配）** | `EXPORT DATABASE` 导出目录（parquet，可独立打开查询） | 逻辑快照；余量 ≥2×need_b 时自动追加（`--backup-mode export` 可强制） |
| **c（必做）** | 记录快照 JSON + `COPY SELECT` JSON 双份 | 记录级快速回滚 |

备份落在 `data/backup/qfq_cutover_repair_<时间戳>/`；路径/sha256/方式写入审计行。

### 3.4 审计行

`data/logs/qfq_cutover_repair_audit.log`（每行一条 JSON），字段包含：
`action / result（ok|rejected|failed）/ old_cutover_id / new_cutover_id / 旧新 aux_db_path /
backups（含路径与 sha256）/ authorization（客户授权依据）/ operator / ts`。
