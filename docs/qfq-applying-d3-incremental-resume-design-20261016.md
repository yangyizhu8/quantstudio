## §2 改动范围（四要点·照裁）

1. **增量裁剪**：`_security_range` 改为**最小窗口集**——按 code 的水位/触发日期取窗口，而非全历史；目标＝与触发规模无关的 **O(增量)** 行为。
2. **断点续跑（按裁＝必需项，非优化项）**：单元级进度持久化（**复用 `qfq_deep_audit_item`**），中断后从断点续、不从头算。
3. **进度/审计复用**：不新增表；`status/attempt_count/updated_at/round_no` 承载。
4. **提交点对齐**：单元级提交与 `qfq_watermark_intent` 的候选/提交语义一致；**禁止单元中途提交**。

**判型**：纯恢复型（把「取全史」恢复为「取所需窗口」的本意）＋ 新增能力型（断点续跑）。**不在本件内**：D2 最小面（`quarantine.py` 顶格背压/告警升级）为独立 mini-件，避免两模块验收混办。
