## 三、豁免与降级机制（防误杀）

- **显式豁免注释**：产物/策略源码中 `# QS_KB_ACK: <QD-id> <理由>` → 对应 BLOCK 降级为 WARN，并在预检报告中留痕（可审计）。
- **降级留痕**：每次豁免写入预检报告（条目 id／理由／操作者），并计入件 C 台账的「豁免计数」列（批 2 增设）。
- **误杀回撤**：若某 BLOCK 判据在实跑中出现误杀（正常转换被阻断）→ 立即降为 WARN ＋ 记 ISSUE ＋ 修订本表（**先修判据再修个案**）。
