## 1 问题定义（今晚违规的机械缺口）

**2026-11-05 00:2x 实测案例**：
- 用户授权推送 **11 笔**（清单末笔 `5eb912c`）
- 执行时 `origin/main..HEAD` 范围实际为 **12 笔**（他线 `4dcdb97` 于授权后 00:15 产生）
- 我方按 C7 全量声明（`QS_PUSH_BUNDLE_ALLOWALSO`）推送了 **12 笔**
- 定性：**申报面规范但推送动作违规**（用声明替代了授权）

**现行闸的能力边界**（`scripts/prepush-gate.ps1`）：

| 能力 | 现状 |
|---|---|
| 验「范围内每一笔都被声明覆盖」 | ✅ 有（未声明即 exit 9） |
| 验「范围内每一笔都在**授权**范围内」 | ❌ **无**（声明可自行填写 ⇒ 等于自审自批） |

⇒ **今晚这类违规在人守层面可防，在机械层面完全无拦截能力。** 本方案补这一维。

## 2 方案设计

### 2.1 授权快照（新增制品）

位置：`docs/evidence/push-authorization/<YYYYMMDD-HHMMSS>.json`

```json
{
  "authorized_at": "2026-11-05T00:20:00+08:00",
  "authorized_by": "用户A令 / 总调度",
  "tip": "5eb912c",                       // ★ 授权清单末笔（锚）
  "commits": ["3e36962", "...", "5eb912c"], // 授权清单全部（含 tip）
  "note": "用户 A 令：11 笔全推"
}
```

**写入时机**：收到授权时**先落快照，再执行推送**（快照是授权的物证，不是事后补录）。

### 2.2 闸判据（核心，两行逻辑）

`pre-push` 闸在现有 C7 声明校验**之前**新增一层：

```
读最新快照 snapshot（无快照 ⇒ 跳过本层，行为与现状一致）
范围 range = commits in (remote_sha..local_sha)
若 local_sha == snapshot.tip：
    ⇒ 合法（锚定授权末笔推送，范围 ⊆ 授权集，结构上不可能超范围）
否则：
    ⇒ range 中存在 ∉ snapshot.commits 的提交 ⇒ exit 9
       提示：「推送 tip 非授权末笔，且存在授权外新增笔 N 个：<SHA列表>；
              正确动作：git push origin <授权末笔>:main，新增笔停手候裁」
```

**为什么这个判据能拦住今晚的违规**：
- 今晚是 `git push origin main:main` ⇒ `local_sha = 4dcdb97(HEAD)` ≠ 快照 tip `5eb912c`
- ⇒ 进入 else 分支，而 `4dcdb97 ∉ snapshot.commits` ⇒ **exit 9 拦截** ✓

**为什么不会误伤**：
- 正常全量推送（范围内每一笔都在授权集）⇒ else 分支通过；
- 锚定末笔推送 ⇒ 直接合法；
- 无快照 ⇒ 行为与现状完全一致（兼容存量流程）。

### 2.3 与现有 C7 的关系

**叠加而非替代**：快照层校验"授权"，C7 层校验"声明"。两层都过才放行。
理由：声明覆盖仍是必要的自证动作；快照解决的是"自证不等于被授权"。

### 2.4 回退

| 维度 | 方式 |
|---|---|
| 快速停用 | `QS_PUSH_AUTH_SNAPSHOT=0` ⇒ 跳过快照层（行为回到现状） |
| 无快照目录 | 自动跳过（不阻断既有流程） |
| 闸自身异常 | **fail-open** 到 C7 层（记录警告），避免闸崩溃阻断一切推送 —— **需②审确认该取向**（另一取向 fail-closed 更安全但可能误锁） |

## 6 需②审裁定的一个取向

**§2.4 闸自身异常时：fail-open（放行到 C7 层）还是 fail-closed（exit 9）？**

| 取向 | 优点 | 缺点 |
|---|---|---|
| fail-open（我倾向） | 闸故障不阻断一切推送，避免"闸坏了全线停摆" | 故障时授权校验静默失效 |
| fail-closed | 安全优先，绝不放过未校验的推送 | 闸 bug 会锁死推送，且需人工绕过 |

**我的建议**：fail-open + **强制 WARNING 落日志**（每次 fail-open 都留痕，便于事后审计发现"校验曾被跳过"）。
