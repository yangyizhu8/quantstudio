## 三、证据（本请求的支撑，全部可复现）

### 3.1 恒等基准（无外部依赖）

`amount/vol` 恒为**该时点的真实可成交价**（金额与成交量在复权下不变）⇒ 可作为**口径裁判**。

### 3.2 单码三点对照（`159327.SZ`，2025-06-03，`adj_factor=1.0`，`is_qfq=true`）

| 源 | close | ÷ 外部基准 |
|---|---|---|
| `etf_daily` | **0.398** | **0.9950 ≈ 1** ✅ |
| `etf_minutes`（当日中位） | 0.133 | **0.3325 ≈ ⅓** ❌ |
| 外部基准（tdx 前复权日线） | 0.40 | — |

### 3.3 两表 `amount/vol` 互不一致（同码同日）

| 源 | amount/vol | close/(amount/vol) |
|---|---|---|
| `etf_daily` | 0.1190 | **3.3445** |
| `etf_minutes` | 1.1930 | **0.1112** |

⇒ 两表 `amount/vol` 约差 **10×**；且各自的 `close` 与自身 `amount/vol` 比值**都不是 1**。

### 3.4 全市场统计（2025-06-03，`etf_daily` n=3,214）

```
close/(amount/vol): 中位 = 10.0005   P10 = 9.5312   P90 = 10.0371   ≈1 占比 = 0.0000%
```

⇒ **稳定在 ~10 的系统性量级差**（不是个别脏行、不是随机噪声）。

### 3.5 跨表 close 比值（2,347 码）

```
minute_close/daily_close:  P50 = 0.9981   ≈1(±1%) = 82.36%   ≈⅓(±5%) = 1.19%
两表 adj_factor 一致率 = 89.69%
```

⇒ 需上游注意：**82% 的「≈1」是在错误价格水平上的一致**（该口径下 `close/(amount/vol)=10`），
故**不能**以"两表多数相等"作为口径正确的证据。

### 3.6 外部基准可用性（说明本请求不是单侧主张）

外部基准（tdx MCP）支持**历史任意日期**前复权 OHLC 查询，实测：
「159327在2025年6月3日的收盘价」→ 前复权 0.40 ⇒ **第三来源可独立复核**。
