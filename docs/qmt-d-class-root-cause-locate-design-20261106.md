## 一、问题定义

### 1.1 实测结果（V7 真机明细 vs 本地基线）

| 维 | V6 首版（EPS 因子缺失，`8261c686`） | **V7（EPS 因子恢复，`b3b3ef9f`）** | 本地基线 |
|---|---|---|---|
| QMT 笔数 | 34 | **35** | 29 |
| D1 调仓日 | QMT 27 / 共同 20 | **QMT 26 / 共同 19** | 22 |
| D2 标的 | QMT 18 / 共同 11 | **QMT 18 / 共同 10** | 15 |
| D3 方向 | buy18/sell17 | buy18/sell17 | buy15/sell14 |
| D4/D5 字段差 | 21 组（qty15／price16／fee21） | **19 组（qty15／price15／fee19）** | — |
| **D 类合计** | **22** | **26（Δ=+4）** | — |

**判定：阈值「≤5」未达成 ⇒ 触发方案件 §七「D 类另有主因」分支 ⇒ V6-判据 v2 不定稿。**

### 1.2 关键观察（决定本件方向的三条）

**① EPS 因子有无，只改变了 1 个选股决策**

V6→V7 的全部变化是：`300321`（06-22 买／06-24 卖）→ `002577`（06-22 买／06-29 卖）。其余 33 笔**完全相同**。
⇒ EPS 的 C/A 因子**只影响 1/35 笔**。
⇒ **D 类 26 笔差异的主因不在 EPS 侧。**

**② composite 对缺失因子是「权重重分配」，不是「剔除」**

`_composite_score` 逐因子加权并按 `wsum`（实际有效权重和）归一化 ⇒ 某因子 NaN 只让其余因子权重变大，**不会**让该标的被 `dropna(subset=['composite'])` 剔掉。
⇒ 「EPS 因子缺失导致候选池坍缩」这一假设**不成立**；真正影响选股的是**因子取值**。

**③ 差异集中在窗口前段，后段几乎完全一致**

| 区间 | 表现 |
|---|---|
| 2026-06-01 ~ 07-07 | **D 类密集**（本地独有 5 只标的 `002568`/`600971`/`600228`/`300321`/`300121` 全部落在此段） |
| 2026-07-15 ~ 09-14 | **几乎完全一致**（`300643`／`300214`／`301376`／`300654`／`601066` 全部命中本地；仅 `300214` 一只未命中） |

⇒ 主因**不是持续性口径差**，而是**随时间衰减的某种「可得性/对齐」差异**。

## 二、根因候选（按可证伪性排序，均未证实）

### 候选 C1｜历史序列**行对齐**差异（停牌日/缺失日的填充口径）——**首选**

- **机制**：策略窗口指标全部基于**序列尾部位置**而非日期对齐：
  `high[-260:-1]`（N）、`close[-251]`（L）、`volume[-60:]`（I）、`close[-61:]`（ret）。
  若两侧对**停牌日/无成交日**的处理不同（本地日线表跳过该日 vs QMT `get_market_data_ex` 补 0 行或压缩），则**同样长度的序列尾部对应不同日期** ⇒ 窗口指标错位 ⇒ 截面排名变 ⇒ 选股变。
- **为何与观察吻合**：错位影响在**窗口前段**最严重（标的刚上市/停牌多、260 根尚未凑齐的年份边界），**随时间推移序列补齐而消失** ⇒ 完美解释「前段差异密、后段一致」。
- **与本项目历史的关联**：停牌/缺失日处理在本项目已多次出问题（QD-2026-0021 停牌判据误用），**属高复发族**。
- **证伪判据**：若两侧对同一 code 的 `hist` 返回**同一组日期序列**（长度与起止日逐位相同），C1 被证伪。

### 候选 C2｜**前复权基期**不同（`fq='pre'` 名义一致、基期不同）

- **机制**：本地 `fq='pre'` 走**仓内 qfq 因子表**（入库时固定基期）；QMT 侧 `fq='pre' → dividend_type='front'`（QMT 端按其自身规则滚动计算）。
  ⇒ 同一个历史日期，两侧前复权价**可能不同** ⇒ `close[-251]`、`high[-260]` 不同 ⇒ **N（250 日新高接近度）与 L（250 日收益率）** 不同 ⇒ 截面排名变。
- **为何与观察吻合**：C/A/S/I 受影响小、N/L 受影响大 ⇒ 仍能解释前段差异（早期因子 N/L 因分母小而敏感）。
- **证伪判据**：若同一 code、同一日期的两侧 `close`/`high` 逐位一致（浮点容差内），C2 被证伪。

### 候选 C3｜**260 根门槛**下的候选池差（硬门槛剔标）

- **机制**：策略 L198 `if len(close) < MIN_HISTORY_BARS(=260) … : continue` ⇒ **历史不足 260 根的标的全被剔除**。
  本地库与 QMT `get_market_data_ex(count=260)` 对「上市不足 260 根」的标的返回长度不同 ⇒ **候选池起点就不同**。
- **为何与观察吻合**：上市晚的标的在窗口前段最容易被剔 ⇒ 前段候选池差异大、后段趋同。
- **证伪判据**：若两侧对全部 universe 返回的 hist 长度分布一致（逐 code 比对），C3 被证伪。

### 候选 C4｜EPS 侧 `ann_date<=T` 过滤窗口/覆盖期差异（**降级为次要**）

- 观察 ① 已表明 EPS 因子只影响 1/35 笔 ⇒ **C4 不可能是 26 笔的主因**，仅作残余解释保留。

## 三、取证方案（一次性定位，不逐个试错）

### 3.1 诊断产物（框架层诊断行 · 铁律 07 零策略改动）

在 wrapper 的历史取数路径**加诊断行**（仅诊断，不改返回语义）：

```text
QS_QMT_FACTDBG code=<code> n=<根数> d0=<首日> d1=<末日> c1=<close[-1]> c5=<close[-5]>
                 c60=<close[-60]> c251=<close[-251]> h260=<high[-260]>
                 v5=<vol[-5:].mean> v20=<vol[-20:].mean> v60=<vol[-60:].mean>
```

本地侧跑**同一段诊断逻辑**（同一实现、两侧共用，禁止各写一套）。

### 3.2 对照标的集（覆盖全部差异模式，11 只）

| 组 | 标的 | 用途 |
|---|---|---|
| 本地独有 | `002568` `600971` `600228` `300321` `300121` | QMT 侧为何没有它们 |
| QMT 独有 | `301439` `301557` `603859` `600060` `002577` `001331` `301093` `300214` | 本地侧为何没有它们 |
| 双方共有（对照组） | `601066` `600027` `600546` `301418` `300307` `301051` `300643` `300654` `301376` | 两侧一致 ⇒ 反证差异源不在通用路径 |

### 3.3 时点对照（3 个窗口，定位「前段密、后段疏」）

| 时点 | 对应选股日 | 用途 |
|---|---|---|
| T1 | **2026-06-01**（首日，D 类最密） | 差异最集中的时点 |
| T2 | **2026-07-08**（中段） | 中间态 |
| T3 | **2026-09-14**（尾段，几乎一致） | 反证组 |

### 3.4 消融矩阵（把「哪个量先分叉」变成可读表）

在 T1 时点，对照表逐 code 输出**首个分叉维度**：

```text
code | n_QMT vs n_LOCAL | d0/d1 是否同 | c1 | c60 | c251 | h260 | v20/v60
→ 首个不等列 = 该 code 的分叉层（长度层 / 日期层 / 价格层 / 成交量层）
```

**判据表**：

| 首个分叉层 | 结论 | 下一步 |
|---|---|---|
| **根数 n 不等** | **C3** 成立 | 查 `get_market_data_ex(count=260)` 实际返回上限/上市不足处理 |
| **根数等但 d0/d1 不同** | **C1** 成立 | 查停牌日/缺失日填充口径（本地跳过 vs QMT 补 0/压缩） |
| **日期同但 c60/c251/h260 不等** | **C2** 成立 | 查两侧前复权基期与因子表 |
| **日期同、价同、v20/v60 不等** | 新候选 **C5**（成交量口径） | 查成交量单位/是否含大宗/是否复权 |
| **全部相等** | 差异在因子**合成/权重**层 | 查 `_composite_score` 权重与 NaN 归一化口径 |

### 3.5 为什么不逐个试错

四个候选（C1~C4）任意两个都可能有叠加效应；逐个试错需 4 轮真机窗口（每轮受 QMT 白天窗口限制），而**消融矩阵 1 轮真机 + 1 轮本地对照即可把「首个分叉层」定位到维度级**。

## 附：本案沉淀要点（供 R4）

1. **「先探测再分级」在真机救了返工**：QD-2026-0022 若当初直接上 P2/P3，会因真机无 `zoneinfo` 模块而整块失效——**分级 + 探测先行**是对「环境不可复现」的唯一稳妥解法。
2. **「修复了 A 缺陷」≠「差异是 A 缺陷造成的」**：本轮 EPS 因子从「整段缺失」恢复为「正常」，D 类却从 22 升到 26 ⇒ 该缺陷**不是** D 类主因，只是恰好影响了 1 笔。
   ⇒ **纪律**：不得把「修好一个显性缺陷后差异仍在」直接归因给该缺陷；差异归因必须**独立取证**（消融矩阵）。
3. **序列位置型指标对「缺失日填充口径」敏感**：策略窗口指标全用序列尾部位置（`[-260:]`/`[-251:]`/`[-60:]`）⇒ 任一侧的停牌/缺失日处理不同即造成错位 ⇒ **窗口类因子在跨系统保真中，须把「日期序列对齐」作为独立一维校验**，不能只比值。
