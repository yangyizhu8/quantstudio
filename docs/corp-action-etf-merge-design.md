> 立项：2026-10-07 用户裁定照准（P1 验收轮）。
> 证据：`docs/evidence/corp-action-etf-merge-2025-09-22.md`（双数学恒等+公告三源+首偏日 9/22）。
> 类型：**数据修正型**（公司行为按正确口径处理；影响面显式声明，见 §4）。

## 1. 问题定义

本地回测引擎的公司行为兜底层 `_apply_factor_derived_split`（backtest_engine.py L919）**存在份额合并分支但三道闸全部拦死 159934 黄金ETF 2025-09-22 合并**（比例 0.948126035）：

| 闸 | 现状 | 159934 实测 | 判定 |
|---|---|---|---|
| ①ratio 源 | `prev_close / preClose`（库 preClose=除权参考价 8.251） | 0.948127（与公告六位吻合） | ✓ 通过 |
| ②吸附规则 | **round(ratio×2)/2（0.5 倍数）+0.5% 容差**，未吸附 WARN+跳过 | snapped=1.0，偏差 5.19%→跳过 | ✗ **根因** |
| ③份额取整 | `int(new_total/100)*100`（A 股整手） | ETF 合并精确到份（平台 3796 非 100 倍数） | ✗ 隐患 |

后果链（已实证）：持仓 4000 份未缩减 × 库价格已按合并后口径（8.408）→ 9/22 nav 虚高 +1715.23 →
9/30 +1780.92 → 回撤判定异号（平台 −6.97% 锁 / 本地 −5.90% 未锁）→ 10/9 调仓数量差 → 11-12 月
换仓分叉 → V2 残差 3.88pp。

**为何 0.5 吸附错误**：半倍数吸附适合送股带（10送5=1.5 类整数比）；**合并带（ratio<0.99）的
比例是任意的**（黄金ETF 0.948126；历史上 162411 等亦有任意比）。而除权参考价由交易所按公告
比例精确计算——**反推 ratio 本身已是六位精度的事实源，无需再吸附**。

## 2. 改动范围（全部框架层，策略文件零改动）

### 2.1 引擎：合并带重设计（backtest_engine.py `_apply_factor_derived_split`）

**仅改 ratio<0.99 合并带**（0.99~1.01 非除权带、1.01~1.10 现金分红带、≥1.10 送股带**语义零变化**）：

```
ratio < 0.99（合并带）：
  1. 边界校验：0.50 ≤ ratio < 0.99（出界→WARN+跳过，防脏数据）
  2. 直接采用反推 ratio（不再 0.5 吸附）——除权参考价精度实证 6 位
  3. 份额取整改按「份」：new_volume = int(round(old_volume * ratio))
     （ETF 合并不按 100 股整手；零头 <1 份自然取整）
     尾差现金：合并缩减不产生现金（份额合并无现金对价，尾份 <1 舍去）
  4. 成本守恒：avg_cost = avg_cost * old_volume / new_volume
  5. 审计留痕：corporate_actions 记录 {type:'etf_share_merge', ratio, 前后份额}
```

## 3. 影响面与不变面（显式声明）

- **变**：凡回测区间含 ETF 份额合并事件且持仓穿越除权日的策略——持仓份额/成本/净值按正确口径；
- **不变**：送股带/现金分红带/股票 stock_dividend 精确路径/订单/撮合/费用/成本口径开关；
- **V3 基线声明**：legacy（moving_avg）旧基线 12.457% 亦含合并缺失错误，修复后将变化（数据修正
  型：diff 只能源于合并事件行集；准确度只升不降）；
- **性能**：每持仓每日一次 ratio 比较（既有路径），零新增扫描。
