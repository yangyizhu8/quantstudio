# PyQt 暗色面板与公共回测日志设计

日期：2026-07-24

## 目标

修复 QuantStudio PyQt 主界面中多个原生 Qt 区域在 Fluent 暗色主题下显示白色背景、浅色字体不可见的问题，同时精简质量检查和策略回测页面，并固定主导航启动时的默认展开状态。

## 范围

本次修改包括：

- 数据源模块使用与 QFluentWidgets 暗色主题兼容的滚动区域。
- 配置编辑模块的数据源凭证、采集任务和字段对齐规则区域显示暗色背景及白色文字。
- 删除质量检查页底部的完整详情栏，保留结果表中的“详情”列。
- 删除策略回测页的独立日志栏，将全部回测日志写入底部公共日志栏。
- 主窗口左侧菜单启动时默认展开，之后仍允许用户手动折叠。

本次不修改配置文件结构、数据源字段模型、采集任务业务规则、质量检查逻辑、回测执行逻辑或日志持久化方式，也不建立新的全局主题系统。

## 主题与界面结构

`main_gui.py` 中的 `setTheme(Theme.DARK)` 继续作为应用唯一的全局主题入口。本次不增加覆盖全部 Qt 控件的全局 QSS，避免破坏 QFluentWidgets 自带的悬停、选中、禁用和焦点状态。

### 数据源模块

`SourceTab` 中的原生 `QScrollArea` 替换为项目其他页面已经使用的 QFluentWidgets `ScrollArea`。滚动区域、视口和内部内容容器应继承 Fluent 暗色主题，不再显示白色底色。现有数据源定义、配置加载和保存行为保持不变。

### 配置编辑模块

数据源凭证、采集任务和字段对齐规则页面中受原生 Qt 调色板影响的容器、滚动视口、表格和输入控件使用局部暗色样式。样式要求如下：

- 背景采用与现有 Fluent 暗色皮肤协调的深色。
- 主文字使用白色，辅助文字使用可读的浅灰色。
- 输入框、表格、滚动区域和内容容器不能残留白色视口。
- 保留边框、选中、悬停、禁用和输入焦点的可辨识状态。
- 不改变配置字段、编辑能力、保存逻辑和数据源优先级规则。

局部样式应集中定义或复用，避免在同一文件中重复散布相同颜色字符串，但不为本次需求引入完整主题令牌架构。

## 质量检查页

删除质量检查页底部的“检查详情”标题和只读详情文本框，并清理相关成员变量和写入逻辑。

检查结果表保留现有“详情”列，继续显示每项检查结果的单行摘要。检查执行、状态统计、成功与失败颜色以及异常处理保持现状。删除详情栏后，页面剩余空间由检查结果表自然占用。

## 策略回测日志

删除策略回测页中的“回测日志”标题和独立日志文本框，并清理对该文本框的引用。

`BacktestWorker` 继续使用现有信号报告加载数据、执行进度、逐日进度、完成和错误消息。`BacktestTab` 接收这些消息后，通过模块级 Python `logger` 写入日志，而不是直接访问 `MainWindow` 的日志控件。

日志显示链路统一为：

1. `BacktestWorker` 发出进度或状态信号。
2. `BacktestTab` 更新进度条和状态文字。
3. `BacktestTab` 使用合适级别的 `logger` 记录消息。
4. 根日志处理器 `GuiLogHandler` 将日志转发到底部公共日志栏。

所有现有回测消息均应出现在公共日志栏，包括加载数据、逐日进度、完成和错误信息。实现时需检查完成及异常路径中已有的日志调用，确保同一事件在公共日志中只显示一次。

进度条和状态文字继续实时更新，删除独立日志栏不得降低回测进度的可见性。

## 左侧菜单

主窗口完成导航项注册后，使用当前安装的 QFluentWidgets 版本提供的公开展开接口，使左侧菜单在应用启动时默认展开。

该行为只设置初始状态：

- 用户仍可点击折叠按钮收起菜单。
- 不禁用折叠功能。
- 不保存或恢复上一次展开状态。
- 不访问 QFluentWidgets 的私有内部属性。

实现前需要核对项目当前依赖版本中的公开 API 名称。

## 错误处理

配置读取、配置保存、质量检查和回测执行继续使用现有异常处理方式，包括日志记录和消息框提示。主题调整不改变业务异常行为。

若局部控件不响应 Fluent 主题，样式应限制在对应页面或控件对象名范围内，不扩大为应用级通配规则。若导航展开接口在当前版本不可用，应选择该版本的等价公开 API；不得通过修改私有状态强制展开。

## 测试与验收

### 静态检查

- 被删除的质量详情文本框不存在残留引用。
- 被删除的回测日志文本框不存在残留引用。
- 新增控件导入有效。
- 导航展开调用与安装的 QFluentWidgets 版本匹配。

### 自动化测试

- 质量检查页保留结果表的“详情”列，但不再创建底部详情栏。
- 回测 Worker 的全部消息经 `BacktestTab` 写入 Python 日志。
- 日志转发不会在完成或异常路径中生成重复消息。
- 数据源和配置编辑相关页面应用暗色背景与白色文字。
- 主窗口初始化后导航处于展开状态，且折叠能力仍然可用。
- 现有配置读写、质量检查和回测相关测试继续通过。

### 实际界面检查

启动 PyQt 应用并检查：

- 数据源页面无白色滚动区域，文字清晰可见。
- 数据源凭证、采集任务和字段对齐规则页面均为暗色背景及白色文字。
- 质量检查页只保留表格中的“详情”列，不显示底部详情栏。
- 策略回测页不显示独立日志栏，所有回测消息只出现在底部公共日志栏。
- 左侧菜单启动时展开，用户点击折叠按钮后可以正常收起。

## 实施边界

预计修改集中在以下文件：

- `quantstudio/gui/tabs/source_tab.py`
- `quantstudio/gui/tabs/config_editor_tab.py`
- `quantstudio/gui/tabs/quality_tab.py`
- `quantstudio/gui/tabs/backtest_tab.py`
- `quantstudio/gui/main_window.py`
- 对应 GUI 测试文件

除非验证表明运行态采集任务页也存在同类白底问题，否则不修改 `TaskTab` 的业务结构。回测结果独立窗口的硬编码暗色样式不在本次范围内。
