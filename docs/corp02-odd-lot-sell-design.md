## 1. 问题定义（截断链已逐点勘察）

**现象**：2026-01-29 四象限清仓单本地 3200 vs 平台 3296（V2'' 残差 2.23% 主源；93 份零股滞留）。

**链路**（策略语义完备，框架层截断）：

| 环节 | 行为 | 判定 |
|---|---|---|
| 策略 `submit_target_amount` 清仓分支（L400-402） | `target=0 且 enable≥current` → sell_amount=**current_amount 全量含零股** | ✓ 语义正确（注释明示"包括零股"） |
| `ptrade_api.order(-3293)` → `_immediate_execute` → L790 | 数量原样传递 | ✓ 无截断 |
| **`_execute_sell` L1208** | `round_to_lot(3293, 100)` = **3200** | ✗ **唯一截断点** |

**平台语义依据**（铁律：先查文档）：
- 依据 Context7 `/kay-ou/ptradeapi`（Ptrade国盛/山西原文档）：`order()` 按指定数量交易，**未对
  order 数量声明整手取整**（仅 `order_target_value` 声明"委托股票时取整 100 股"）——数量式 API
  按委托量成交；
- 平台日志实证：2026-01-29 卖出 159934 **3296 股原量成交**（非 100 倍数）；
- A 股规则：卖出允许零股一次性卖出（买入必须整手）。
