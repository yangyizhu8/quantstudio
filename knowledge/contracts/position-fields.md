## §1 POS-01 `cost_basis` 每股持仓成本 ⚠️已知分歧（修复中）

### 平台口径（权威，已实证）

**摊薄成本法（净投入法）**：

```
买入：cost_total_new = avg_cost × volume + 成交额 + 佣金 + 过户费
卖出：cost_total_new = avg_cost × old_volume − 卖出净得
      （卖出净得 = 成交额 − 佣金 − 印花税 − 过户费）
avg_cost = cost_total_new / 持仓量；清仓归 0；负值钳 0
```

**平台实证（四象限ETF轮动案例，2024 年序列，四位吻合）**：

| 日期 | 操作 | 摊薄推演 | 平台日志显示 |
|---|---|---|---|
| 01-02 | 建 54000@0.925 | 0.9250 | 0.925 |
| 04-01 | 卖 41500@1.015 | 0.5569（剩余10500股） | — |
| 07-01 | 买 40600@1.078 | 0.9701 | — |
| 09-02 | 买 500@1.006 | **0.9731** | **0.973** ✓ |
| 09-11 | 买 1900@0.944 | 0.9725 | 0.972 ✓ |

### 本地现状（缺陷）

- `backtest_engine.py` L1166 买入加权（**不含费用**）；L1214 卖出减持**不改成本**（买入移动加权）；
- `ptrade_api.py` L214 直接透传引擎 avg_cost 给策略 `cost_basis`。
- 后果：4/1 大额盈利卖出后双端成本分叉（0.557 vs 0.925），9/4 现价 0.993 下本地判定 −5.01%
  触发止损、平台 +2.05% 不触发 → 双端收益差 43.74pp（详见归因报告）。

### 修复状态

- 方案件：`docs/cost-basis-diluted-alignment-design.md`（六步①已呈，待总调度审核）
- 契约测试：`tests/test_cost_basis_diluted.py`（修复实施时新增，黄金值用上表平台实证序列）
- 修复落地后本条目 → 已锚定。

### 已知精度边界

- 费用含/不含对成本影响 ~1e-5/股（本案例佣金 5 元/5 万股级），平台日志 4 位精度不可分辨；
  默认含费（净投入完备口径）；
- 负摊薄成本（极端大额盈利卖出）平台行为未实证——本地钳 0 + 审计留痕。
