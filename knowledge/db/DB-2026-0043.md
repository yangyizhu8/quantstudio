## 复现步骤

1. 取两值域：量 `ratio`（分钟末收 / 日线收）与量 `ff = adj_D / latest_now`（修正因子）。
2. 构造一条**旧锚（raw）行**：某码某日的分钟末收写于当日（当时 `latest == adj_D`），而日线已重锚到当前 `latest`。
   此时必有 `ratio == latest_now / adj_D == 1/ff`。
3. 施加**错误判据** `|ratio - ff| <= tol`（tol=0.005）⇒ 该行**不被判为 B**，反而落入 C
   （除非 `ff≈1` 时偶然命中）。
4. 施加**正确判据** `|ratio*ff - 1| <= tol` ⇒ 该行被判为 B，`dev_raw` 实测 ~1e-5 量级。
5. 实证锚点（本地 QuestDB 只读）：
   - `001211.SZ` 2026-06-03：`ratio=1.3890`、`latest/adj_D=1.3891` ⇒ 两法一致 ⇒ B
     （`scripts/qfq_reanchor_minutes.py` 实测 `cross_rel_diff=9.23e-06, conflict=False`）；
   - `000063.SZ` 2026-07-14：`ratio=1.000000` ⇒ A（已同锚）；
   - `603409.SH` 2026-06-17：`ratio=1.504509`、`ff=0.664658` ⇒ `|ratio*ff-1| = 1.7e-5` ⇒ **是精确旧锚行**，
     而 v1 报告用它作「不是错锚」的 C 类反例 ⇒ **反例本身被误分类**。
6. 全量读数（`--census 300 --seed 42`，只读）：
   正确判据 B 类 **69/189 = 36.5%**；错误判据 B 类 **2/189 ≈ 1.0%** ⇒ 差 ≈ 37 倍。

## 讨论

### 一、为什么会写反（可复用教训）

1. **`ff` 与 `ratio` 是同一件事的两种表述**：`ff` 是「要乘多少才回到当前锚」，`ratio` 是「现在差多少」，
   二者**互为倒数**。写成 `|ratio - ff|` 就像把「涨跌幅」与「涨回原位需涨多少」直接相减——
   量纲相同（都是无量纲比值）但**语义相反**，属「看似合理的同类量误配」。
2. **判据写反时的读数特征**（本次即命中）：
   - B 类占比**对容差极不敏感**（0.2%→5% 全程 1.0%）——真实现象不会这么稳；
   - C 类占比**畸高且随容差单调塌缩**（54%→5.6%）——说明 C 类是「两种假设都不贴近」的混合桶，
     而非「真异常桶」；
   - 「与被测工具自带的交叉校验不一致」是最强信号：工具用 `fix_factor` vs `fix_factor_daily` 相等判 raw，
     普查脚本却用别的式子 ⇒ **两处必有一处错**，而工具那处有数学推导背书。
3. **反例表反查法**：把报告自己引用的反例逐条代入正确判据重算——本次一步即定位
   （`603409.SH` 的 `|ratio*ff-1| = 1.7e-5`）。**报告的反例是最便宜的复核样本**。

### 二、修正后的三条定谳（已进入工具与 L2 方案）

1. **raw 判据**：`B ⟺ |ratio*ff − 1| ≤ tol`（等价于两法 `fix_factor` 与 `1/ratio` 相等）。
2. **回放因子是逐 (码, 段) 的，不是逐码常数**：实测同一码同一因子区间内并存 ratio=1.0 与 ratio=1.48 的行
   （后期回填行按当前锚写入）⇒ 禁止「按码乘一个 ff」；分钟表 `adj_factor` 列存 `a(t)` 而非写时锚 `a_write`，不可当因子用。
3. **落点形态需裁决**：QuestDB 分钟表无 raw/front 分列，原地乘 `close` 会**不可逆地摧毁 raw 锚信息** ⇒ 倾向增列保留双口径。

### 三、两条后续定谳（2026-11-11 段级计划器落地时补入）

**定谳 A：段级分类**只用 `ratio`**，`ff` 降级为**来源证据**。段级 `ff` 取自「区间因子/a_latest」，而写入锚
`a_write` 与区间因子**未必相等**（后期回填行写在**中间锚**上，其区间因子仍是交易日因子 a(t)）⇒ 用
`|ratio*ff-1|` 判段级会把这类「已偏离当前锚、但不是自锚批」的行误判成「禁改/人工」。
实测：000063.SZ 区间 factor=16.7756 的抽样日 ratio 均 1.01219（写在 17.1055 锚上）⇒ 实为**可回放**行；
40 码无偏样本中 **66%（31/47）的可回放段属此类「中间锚」批**——旧口径会漏掉的主体。
正确分层：**普查（单检验点，除权点前一日）**用 `|ratio*ff-1|`（该处 `a_write==a(t)`，判据成立）；
**段级/行级**用 `|ratio-1|`（修正因子恒等式 `回放目标 = 落库值 ÷ ratio`，不依赖 ff）。

**定谳 B：因子区间分区 ≠ 写入批分区**。`stock_minutes.adj_factor` 列存的是**交易日因子 a(t)**，不是 `a_write`
（两表因子区间边界逐位一致已证）。实测：000063.SZ 的区间 factor=16.7756 与 factor=17.1055 **同属 17.1055
写入批**（ratio 同为 ≈1.0122）；603271.SH 的 factor=1.0/1.009 两区间 ratio 同为 1.01457。
⇒ **回放段必须按跨区间的 ratio 簇定义**，禁止「按因子区间整段乘一个因子」；
且引擎侧 bootstrap 多簇的变点解释（`explain_changepoints` 要求每个变点有除权事件解释）会因
**回填批边界不是除权日**而整券 BLOCK ⇒ 须扩展示释源。
