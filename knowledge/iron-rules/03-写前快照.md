## 【铁律】代码层"写前快照"纪律（多会话共享工作区防护）

背景（2026-08-17 事故）：多会话共享同一 git 工作区 + 并行未提交改动 + 批量破坏性 git 操作
（checkout/reset/revert），曾覆盖另一会话的未提交工作（后经 dangling blob 找回）。
本纪律与数据层快照原则同构，防止同类事故重演。

1. **任何批量/破坏性 git 操作（checkout -- / reset / revert / clean / stash pop 冲突覆盖）前，
   必须先建零副作用回退点（四步配方，2026-10-12 修订；2026-10-14 定 scope 再修订）**：
   `git add -A -- <本会话涉及路径>`（未跟踪新建文件入暂存——**定 scope 变体，2026-10-14 修订**：
   全仓 `git add -A` 在共享工作区有两起实证风险——一次暂存 694 条他线未跟踪件制造"无 pathspec
   commit 卷入"窗口、且嵌入仓库致超时 >10min〔QMT 线案〕；scope 限定后仍完整捕获本会话未跟踪件。
   另 **`git stash create` 不接受 `-u`**，旧配方中 `-u` 会被并入 message、未跟踪文件从不入 stash；
   2026-10-12 trading-runtime 1,619 行委派产物因此不可逆丢失，实测定谳）
   → `git stash create "baseline-<时间戳>"`（只建对象不动工作区）
   → **随即 `git stash store <hash>` 持久化**（create 产出的对象无引用、可被 `git gc` 清理；
   store 固定进 stash 引用后才防丢）
   → `git reset`（撤暂存、不动工作区）。
   将返回的 commit hash 记入会话记录或登记表；误操作后 `git reset --hard <hash>` 找回。
   **引用/删除/回退前必 `git stash show --stat <hash>` 核对内容**——"有回退点"≠"回退点里有东西"；
   引用 stash 内容一律**按路径单文件提取**（`git show <hash>:<path>`），禁整仓 pop
   （stash 可能混入他线未提交改动，2026-10-12 案实证）。
2. **操作前核对目标文件状态**：`git status --porcelain` 确认待回退文件是否含**其他会话的
   未提交改动**（非本会话创建的 M 文件一律视为他人工作，禁止盲回退）。
3. **每轮会话开始时记录工作区基线**：`git status --porcelain` + `git diff --stat`
   落盘到 `docs/handoff/`（轻量基线，供溯源）。
4. **回退优先用逐文件定向手段**（文件级 cp 备份/恢复、Edit 工具），
   批量 git 回退是最后手段且必须在回退点建立之后。

## 修订（2026-11-10 用户裁定甲·脏工作树场景·草案⑫→②审→⑤批全链）

> 触发：2026-11-09 性能线实测——脏树（855 项）下按原四步配方执行，`git stash create`
> 实际捕获整树 40 文件、其中**他线未提交改动 39 个**（后续㉑/⑤ 两案再证 13/3 个）。
> 三后果：误 `pop` 连带恢复他线改动（跨会话污染）；stash 编号与他线交错致误删他线回退点；
> 原第①步 `git add -A` 本身即跨他线 stage（反向串车族）。

- **A 脏树判定**：操作前先 `git status --porcelain`；**存在非本会话的 M/?? 条目 ⇒ 判脏树**，
  判定结论（哪几个是他线）落盘交接件/会话记录。
- **B 脏树禁 stash create，改定向 patch 锚**：`git diff --output=<anchor>.patch -- <本会话路径逐一显式>`
  （已暂存用 `--cached` 变体）；**禁 PS 5.1 `>`/`Out-File` 写 patch**（UTF-16 致不可用）；
  patch 锚登记 sha256+路径；**B5 兜底：他线改动与本会话无法按路径隔离（同一文件混两方改动）
  ⇒ 不得用 patch 锚（会连对方改动一起锚/退），停手上呈总调度裁定**。
- **C E-6 验证句**：**任何形式**回退点建后立即验可用——patch 锚 `git apply --check --reverse`
  通过；stash `git stash show --stat` 能列出预期文件。验证不过 ⇒ **视同没有回退点**，停手重建。
  理由入条款：**建了用不了的回退点比没建更危险——它让人以为有退路。**
- **D 原条款保留**：精确路径精神（任何 add/diff/patch 显式列路径，禁 `-A`/`.` 跨路径）；
  逐文件定向回退优先；原⑤引用前核对由 C 扩展覆盖一切形式；`create` 不受 `-u`/不 store 被 gc
  两条保留（脏树下根本不该走这条路）。净树（无他线条目）仍可用原四步配方。

配套：铁律 10 第①条「按 03 号四步配方」改读「按 03 号**修订后**配方（脏树用 patch 锚）」。
