# 平台文档库 · 标签索引（受控词表）

## 二、内容类型类（可选，可多选）

| 标签 | 含义 |
| --- | --- |
| `类型/入门安装` | 环境安装、客户端配置、快速上手 |
| `类型/API参考` | 函数／接口签名、入参、返回、示例 |
| `类型/数据字典` | 常量枚举、字段含义、代码格式 |
| `类型/交易执行` | 下单／撤单／委托／成交／账户查询 |
| `类型/策略生命周期` | 初始化／盘前／Bar／盘后／结束／回调 |
| `类型/回测框架` | 回测 API、context 对象、设置函数 |
| `类型/示例教程` | 场景化示例、完整示例、公众号文章 |
| `类型/FAQ` | 常见问题与排错 |
| `类型/版本说明` | 平台版本更新说明（漂移线索） |
| `类型/HTTP接口` | HTTP 方式调用 |

## 三、状态类

| 标签 | 含义 |
| --- | --- |
| `状态/已抓取` | 已抓取入库，含源 URL 与抓取时点 |
| `状态/待复核` | 已入库但尚未与运行实测核对 |
| `状态/已知偏差` | 已确认与实测不一致（**以实测为准**，页内标注） |
| `状态/部分缺失` | 站点存在但本轮未抓到（逐条列出原因） |

## 四、治理类

| 标签 | 含义 |
| --- | --- |
| `治理/来源第三方` | 内容版权属平台方（全库默认） |
| `治理/仅私有分发` | 只随私有 VIP 仓分发，不进公开仓 |
