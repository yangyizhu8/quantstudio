# 平台文档库 · 本库定位与来源许可声明

## 一、本库定位

本库为 **QuantStudio-trading 项目全流程管线（回测 ＋ 模拟盘 ＋ 实盘）** 的**外部平台文档参考层**，收录目标平台的官方操作与 API 文档**快照**，用于：

| 用途 | 说明 |
| --- | --- |
| **离线可查** | 不依赖外网与第三方服务即可检索平台 API 与操作说明 |
| **随仓分发** | 随本项目私有仓分发，持有仓库者（含 VIP 客户）可直接查阅 |
| **版本对照** | 借抓取时点与页哈希，可对照平台文档的**漂移**（哪一版改了什么） |
| **全文检索** | 支持仓库内 grep／Obsidian 全文搜索（第三方服务只按主题返回片段，做不到） |

**不承担的用途**：**不作为契约与判据**——平台文档与真实客户端行为可能不一致，**一律以运行实测为准**（见 `index.md` 顶部声明）。

## 二、★ 来源与许可声明（第三方内容）

| 项 | 内容 |
| --- | --- |
| **内容归属** | 各平台官方文档的**著作权归各平台所有**（TDX／通达信：深圳市财富趋势科技股份有限公司；QMT／迅投；PTrade／恒生电子） |
| **本库性质** | **抓取快照**，用于本项目内部与 VIP 客户的**学习参考**；**非商业再发布**、不主张任何权利 |
| **原始来源** | TDX：`https://help.tdx.com.cn/quant/docs/markdown/`（逐页 URL 见各平台 `_meta/sources.md`） |
| **抓取时点** | 见各平台 `_meta/crawl-manifest.json` 的 `crawled_at`（**每次抓取必须记录**） |
| **★ 分发红线** | **本库只随私有 VIP 仓（`quantstudio-trading`）分发；不得进入公开仓（`quantstudio`）**——公开仓保持纯回测产品边界，且第三方内容入公开仓有版权风险 |
| **删除请求** | 若权利人要求移除，按权利人意见即时删除对应目录并登记 |

## 三、抓取元数据约定（三标记，强制）

每一批抓取必须产出并在本库登记：

| 标记 | 落点 |
| --- | --- |
| **抓取时点** | `<平台>/_meta/crawl-manifest.json` → `crawled_at`（ISO 8601，北京时间） |
| **源 URL** | 逐页 `<平台>/_meta/sources.md`；清单内 `url` 字段 |
| **版本线索** | 站点若有「版本更新说明」类页面，须抓取并在此登记其链接与摘要（如 TDX `TdxQuantVersion.html`） |

## 四、目录约定

```
platform-docs/
├── index.md                 # MOC（vault 根）
├── README.md                # 本文件：定位 + 来源与许可声明 + 元数据约定
├── 标签索引.md               # 受控词表（平台／内容类型／状态）
├── harness/write-rules.md   # 本库写入规则（谁可写／必写／禁写／长度上限）
├── <平台>/                   # tdx/ ｜ qmt/ ｜ ptrade/
│   ├── index.md             # 该平台分域 MOC（按语义分类，非照抄站点 hash 目录名）
│   ├── <语义分类>/…          # 正文（保源 URL 可回溯）
│   └── _meta/
│       ├── crawl-manifest.json   # 抓取清单：url／title／crawled_at／sha256
│       └── sources.md            # 逐页源 URL 对照表
└── _notes/                  # （可选）人工批注，与原文严格分离
```
