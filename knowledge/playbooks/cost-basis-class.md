# 类剧本 · 成本口径分歧（POS-01 cost_basis class）

> 首个类剧本，由四象限ETF轮动案例沉淀（2026-10-06）。
> 症状特征：双端前段逐笔一致 → 某日一笔「单边触发」（本地止损/解禁/条件单触发，平台无动作或反向）→ 此后全序列分叉。

## 症状指纹（快速识别）

- 双端**基准收益逐位一致**、调仓日/象限判定/委托序列前段完全一致；
- 首笔分歧是**条件触发类委托**（止损/成本解禁），且当日行情温和（无涨跌停/停牌）；
- 分歧日现价对策略阈值的距离：本地「贴线越阈」（如 −5.01% vs 阈值 −5.00%）、平台远离边界。

## 诊断步骤

1. 取分歧日双端该标的的**持仓成本**对账：平台日志盘后行 `成本=X` vs 本地推演；
2. 推演本地成本口径（买入移动加权：仅买入加权、卖出不改）与平台（摊薄净投入法：
   见 [../contracts/position-fields.md](../contracts/position-fields.md) §1 公式与实证表）；
3. 验证：平台口径按其交易路径递推 → 与日志显示四位吻合即实锤；
4. 计算判定带：`阈值成本 = 现价/(1−止损阈值)`，确认本地成本落带内、平台成本带外。

## 边界场景（修复后仍需探针覆盖）

- 亏损卖出摊薄（成本被**抬高**——反向影响止损判定）；
- 现金分红/送股与摊薄共存序列；
- 负摊薄钳 0 场景（大额盈利卖出后剩余份额）。
