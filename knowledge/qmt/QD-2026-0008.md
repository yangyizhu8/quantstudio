## 三条陷阱（逐条）

### ① sid 形态：裸码 + 交易所分离，且交易所值 = `SH`/`SZ`
- 实测：`m_strInstrumentID='510360'`（**裸码，无后缀**）、`m_strExchangeID='SH'`
- wrapper 现状：`_qs_get_positions`（`source_import_qmt.py:759-763`）**已做后缀拼装** →
  `if exch and '.' not in code: code = '%s.%s' % (code, exch)` ⇒ 产出 **`510360.SH`**
- 本地口径（**已确证**）：`backtest_engine.py:2638-2641`（`_get_ptrade_positions`＝本地持仓契约**唯一产出点**）文档明载「**Keys use .SS/.SZ**」且「deliberately keeps **normal dict membership semantics**」⇒ 本地持仓字典键＝`.SS/.SZ` ＋ **精确成员语义**（`code not in get_positions()` 即存在性判定）
- QMT 口径（**已确证**）：wrapper `_qs_get_positions:761-762` 拼 `<code>.<m_strExchangeID>`；端测实测 `m_strExchangeID='SH'` ⇒ 键＝`.SH/.SZ`
- ⇒ **跨端键形态差异已确证（`.SH` ↔ `.SS`）**。影响面分层：
  - `DataDict` 路径**不受影响**（`_bare()` 裸码归一）；`get_positions(security)` 单标查询**不受影响**（`_lookup_position` 裸码归一）
  - **字典键路径**（`get_positions()` 无参）本地为**精确成员语义** ⇒ 若两端键形态不一致即 **miss** ⇒ **控制流改变**（本地注释原文警告：making this mapping alias-aware changes real strategy control flow）
  - 已定位的精确键消费方（影响面清单）：`SG-MS-PEG-HL:491/557/595`、`四象限ETF轮动:306/797/1171`、`tech_etf_mvo_rotation:395`、`周频小市值成长动量:344`
- **闭合方案（最小验证项，1 次读数）**：交易端读 `get_all_securities()` 键形态（QMT 原生 universe 码）与 wrapper 持仓键同证——若同为 `.SH` ⇒ **QMT 运行时端内自洽、无 miss**（差异仅为跨端口径记录）；若为 `.SS` ⇒ **真缺陷** ⇒ 走六步流水线修 wrapper 后缀映射（SH→SS）
- 该点即 wrapper 注释所标「**→【M5 实测项】字段名/后缀形态复核**」——**本次端测已确证 QMT 侧 = `SH`**

### ② 空串 ≠ None
- 实测：`m_strOpenDate=''`、`m_strExpireDate=''`（现货持仓无开仓日/到期日）
- 正确判空：`if not v:` ；错误写法：`if v is None:`（空串不是 None ⇒ 误判为「有值」）

### ③ 哨兵/垃圾值禁消费
| 字段 | 实测值 | 性质 |
| --- | --- | --- |
| `m_dStaticHoldMargin` | **1.7976931348623157e+308** | DBL_MAX 哨兵（未使用字段） |
| `m_nCidRateOfCurrentLine` | **−1618221407** | 不可解释（未初始化内存/编码值） |
| `m_nCidRateOfTotalValue` | **1954115676** | 同上 |

## 讨论

- **与 QD-2026-0001（GBK 编码族）、QCAL-05（endDate 空串→静默空）同属「静默语义陷阱族」**——共同特征：
  平台不抛错、不告警，按「常规直觉」消费即得到错误结果。**该族判据**：任何「无值占位」都须显式验证形态，
  禁止假设 None / 假设有值 / 假设单位。
- **回哺方式**：本条目可被件 D（`scripts/qmt_kb_preflight.py`）机读命中（frontmatter `fix_layer: wrapper`）；
