# QD-2026-0010 印花税分期间切换

## 事实（实测定位）

本地 `backtest_engine.py:885-889`：

```python
def _stamp_tax_rate(self, date: str) -> float:
    ...
    return min(float(self.cost.stamp_tax_rate), 0.0005)   # 特定日期后封顶
    ...
    return float(self.cost.stamp_tax_rate)
```

- `TradeCost.stamp_tax_rate` 默认 **0.001**（卖出单向，注释标"对齐 Ptrade"）；
- 但 `_stamp_tax_rate(date)` 在**特定日期之后**把费率**封顶为 0.0005**；
- 卖出计提：`net_proceeds = proceeds − commission − stamp_tax − transfer_fee`（`:1248-1250`）。

⇒ **印花税不是常量，随日期切换**。疑对应 2023-08-28 印花税减半，**但切换点与平台是否一致未核对**。

## 风险（为什么必须登记）

跨切换日期的长周期回测：若本地与平台切换点不同一步，则**切换日前后每笔卖出费率差一倍**（0.001 → 0.0005 或反之），
误差随卖出笔数线性累积 ⇒ **属长周期回测精度口径点**，不是小偏差。

## 待验判据（已入端测清单）

取一个**切换日前后各含卖出交易**的样本窗口，两端同参跑：

1. 本地：`_stamp_tax_rate(before) == 0.001`、`_stamp_tax_rate(after) == 0.0005` 且**切换日与该日期边界一致**；
2. 平台（QMT 回测面板「卖出印花税」）：控制在切换日前后分别设值或确认平台内建切换逻辑；
3. **判据**：同一卖出样本在切换日前后，两端成交后净额逐笔一致（差 < 1e-9）。

## 与之配套

- 端测清单新增项（`docs/evidence/dat-11-dims-enumeration-20261022.md` §四）；
- FEE-03 已升级「已锚定（本地分期间）」——**QMT 侧切换点仍未验**；
- QMT 回测面板「卖出印花税」为**单一比例字段**（无期间维度，见 `docs/evidence/qmt-backtest-panel-fee-qmch-20261022.md` §一）
  ⇒ 若平台不支持分期间，则**跨切换日期的 QMT 回测无法与本地对齐**，需要"分段回测拼接"或"显式声明已知差异"。

## 端测定谳（2026-10-23，探针 v6）

**结论：QMT 回测引擎印花税为单一费率（按面板值收取），不实施 2023-08-28 分期间减半。**

| 侧 | 卖出日 | 卖出成交额 | 印花 | **印花率** |
| --- | --- | --- | --- | --- |
| 切换前 | 2023-08-23 | 924.207 | 0.9246 | **0.10004%** |
| 切换后 | 2023-08-30 | 1405.00 | 1.405 | **0.10000%** |

**算据**（两侧同面板：佣金 0.0350／最低 5.000／卖印花 0.1000／滑点 0）：
- 切换前：买 000001.SZ @9.34（934.00+5.00=939.00）→ 卖委托 9.23 被引擎改写为 **9.24207**（WARNING：不在当日区间 [9.23385, 9.38172]）⇒ gross 924.207 − 佣金 5.00 − net 918.2824 = 印花 0.9246。
- 切换后：买 000002.SZ @14.2（1420+5=1425）→ 卖 @14.05（无改写）gross 1405.00；**同 bar 尚有跌停买入 000712.SZ @14.81（1481.00+5.00=1486.00）** ⇒ `bar9 delta = −87.405 = 卖出净得 − 1486` ⇒ 卖出净得 **1398.595** ⇒ 印花 = 1405 − 1398.595 − 5 = **1.405**。

**口径边界（重要）**：本结论仅覆盖**回测引擎**。**实盘柜台**按国家税率收取（2023-08-28 后 0.05%），必然分期间 ⇒**实盘口径未验**（不在回测探针能力内）。因此**不得以回测结论否定本地分期间逻辑**——若本地用于实盘对照，分期间是对的。
